# 고객 관리 - 고객 검색 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 고객 관리 / 고객 검색
**SDLC 단계:** 요구사항

## 1. 개요

1차 범위에서는 별도의 검색 기능을 제공하지 않는다. 운영자는 전체 목록(`GET /api/customers`)에서 클라이언트 사이드 필터만 사용한다.

## 2. 사용자 시나리오

- 운영자가 전체 목록을 받아 화면에서 ctrl+F로 찾아본다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 검색-01 | (보류) | 서버 검색 API 미제공 | 후순위 |

## 4. 업무 규칙

- 1차에서는 별도 검색 엔드포인트 없음.
- 2차에서 이름/전화번호 부분일치 검색 API 도입 예정.
