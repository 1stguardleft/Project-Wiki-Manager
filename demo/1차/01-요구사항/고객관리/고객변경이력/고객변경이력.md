# 고객 관리 - 고객 변경 이력 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 고객 관리 / 고객 변경 이력
**SDLC 단계:** 요구사항

## 1. 개요

1차 범위에서는 고객 정보의 변경 이력을 별도 보존하지 않는다. 수정 시 최신 값으로 덮어쓴다.

## 2. 사용자 시나리오

- 운영자가 고객 정보를 수정하면 즉시 반영되며, 과거 값은 시스템에서 조회할 수 없다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 이력-01 | (보류) | 변경 이력 미보존 | 후순위 |

## 4. 업무 규칙

- 변경 이력 테이블 없음.
- `updated_at` 컬럼만 최신 수정 시각 저장.
