# 대시보드 - 집계 통계 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 집계 통계
**SDLC 단계:** 요구사항

## 1. 개요

운영자가 매일 아침 한 화면에서 **회사 전체의 현황을 한눈에** 파악할 수 있도록, 핵심 마스터 데이터의 건수를 집계해 보여 준다. 별도 검색 없이 단일 호출로 모든 카운트를 가져온다.

## 2. 사용자 시나리오

- 영업 시작 시 매니저가 대시보드를 열어 **등록된 상품·고객·직원·주문이 몇 건인지** 확인한다.
- 회의 자료 작성 시 운영자가 현황 수치를 캡처해 공유한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 집계-01 | 전체 상품 수 | 등록된 상품의 총 건수를 반환 | 필수 |
| 집계-02 | 전체 고객 수 | 등록된 고객의 총 건수를 반환 | 필수 |
| 집계-03 | 전체 직원 수 | 등록된 직원의 총 건수를 반환 | 필수 |
| 집계-04 | 전체 주문 수 | 등록된 주문의 총 건수를 반환 | 필수 |
| 집계-05 | 단일 응답 | 4개 지표를 한 API 호출로 묶어 반환 | 필수 |

## 4. 응답 정보

| 항목 | 형식 | 설명 |
|---|---|---|
| productCount | 정수 | 전체 상품 수 |
| customerCount | 정수 | 전체 고객 수 |
| employeeCount | 정수 | 전체 직원 수 |
| orderCount | 정수 | 전체 주문 수 |

## 5. 업무 규칙

- 삭제된 레코드는 카운트에서 제외한다.
- 부서 수는 본 집계 항목에 포함하지 않는다(별도 화면에서 조회).
- 권한 구분 없이 로그인한 모든 사용자에게 동일 결과를 반환한다.

## 6. 비기능 요구사항

- 응답 시간 1초 이내, 동시 호출 50건까지 안정 처리.
- 매 호출 시 실시간 카운트(캐시 없음).

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 특정 도메인 조회 실패 | 해당 항목만 0으로 응답하고 다른 지표는 정상 반환 |
