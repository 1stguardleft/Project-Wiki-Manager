# 직원 관리 - 급여/인사 정보 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 직원 관리 / 급여/인사 정보
**SDLC 단계:** 요구사항

## 1. 개요

직원의 급여(salary), 직책(position), 입사일(hireDate)을 등록·조회·갱신한다.

## 2. 사용자 시나리오

- 인사 담당자가 직원 등록 시 급여·직책·입사일을 입력한다.
- 매니저가 직원의 직책을 변경한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 인사-01 | 급여 저장 | salary 컬럼 보유 | 필수 |
| 인사-02 | 직책 저장 | position 컬럼 보유 | 필수 |
| 인사-03 | 입사일 저장 | hireDate 컬럼 보유 | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| salary | 선택 | 정수 | 급여(원/월) |
| position | 필수 | 문자열 | 직책 (자유 입력) |
| hireDate | 선택 | 날짜 | 입사일 |

## 5. 업무 규칙

- 직책은 자유 문자열 (1차 범위 내 enum 없음).
- salary는 음수 불가.
- hireDate는 미래일자 허용 (예정 입사).

## 6. 비기능 요구사항

- 저장/수정 응답 0.5초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| salary 음수 | 400 |
| position 누락 | 400 |
