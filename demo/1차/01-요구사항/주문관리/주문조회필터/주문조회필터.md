# 주문 관리 - 주문 조회 필터 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 주문 조회 필터
**SDLC 단계:** 요구사항

## 1. 개요

전체 주문 목록은 양이 많아져 가독성이 떨어지므로, **고객별 / 상태별** 단순 필터 조회 API를 별도로 제공한다.

## 2. 사용자 시나리오

- 영업 담당자가 특정 고객의 주문을 모아 본다.
- 운영자가 PENDING 상태 주문만 모아 본다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 필터-01 | 고객별 조회 | 특정 고객의 주문 목록 | 필수 |
| 필터-02 | 상태별 조회 | 특정 상태의 주문 목록 | 필수 |

## 4. 관리 정보

별도 컬럼 없음. 조회 조건만 정의.

## 5. 업무 규칙

- 고객별 조회: `GET /api/orders/customer/{customerId}`
- 상태별 조회: `GET /api/orders/status/{status}`
- 기간/페이지네이션은 1차 범위 아님.

## 6. 비기능 요구사항

- 조회 응답 1초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 잘못된 status 값 | 400 |
| 존재하지 않는 customerId | 빈 배열 반환 (오류 아님) |
