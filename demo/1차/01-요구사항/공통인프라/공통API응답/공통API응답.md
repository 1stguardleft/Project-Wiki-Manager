# 공통/인프라 - 공통 API 응답 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 공통/인프라 / 공통 API 응답
**SDLC 단계:** 요구사항

## 1. 개요

모든 도메인 API가 동일한 형태로 응답하도록 공통 응답 표준을 정의한다. 클라이언트가 응답 파싱에 일관된 코드를 쓸 수 있게 한다.

## 2. 사용자 시나리오

- 프론트엔드 개발자가 모든 API 응답에서 `success`/`data` 필드를 일관되게 추출한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 응답-01 | 성공 응답 | `{ success: true, data: ... }` 형태 | 필수 |
| 응답-02 | 실패 응답 | `{ success: false, data: null }` 형태 | 필수 |

## 4. 응답 구조

| 필드 | 형식 | 설명 |
|---|---|---|
| success | boolean | 성공/실패 |
| data | object/array/null | 실제 데이터 |

## 5. 업무 규칙

- HTTP 상태코드는 별도로 사용 (200/201/204/4xx/5xx).
- 1차에서 응답에 message·errorCode·timestamp는 포함하지 않음.

## 6. 비기능 요구사항

- 직렬화 추가 지연 무시 가능 수준.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 응답 직렬화 실패 | 500 (전역 예외 처리에서 처리) |
