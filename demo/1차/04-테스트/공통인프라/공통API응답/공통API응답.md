# 공통/인프라 - 공통 API 응답 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 공통/인프라 / 공통 API 응답
**SDLC 단계:** 테스트

## 1. 테스트 범위

ApiResponse 직렬화·역직렬화 정확성, 모든 도메인 응답 표준 준수.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| API-N1 | 성공 응답 | 도메인 GET | API 호출 | `{success:true, data:...}` |
| API-N2 | 데이터 null | 응답 데이터 없음 | DELETE | `{success:true, data:null}` |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
