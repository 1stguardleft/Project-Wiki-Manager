# 대시보드 - 집계 통계 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 집계 통계
**SDLC 단계:** 테스트

## 1. 테스트 범위

`GET /api/dashboard/stats` 단일 엔드포인트의 정확성·응답 시간·예외 동작을 검증한다.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| STAT-N1 | 기본 응답 | 상품·고객·직원·주문 각 1건씩 등록 | GET /api/dashboard/stats | 4개 카운트 모두 1 |
| STAT-N2 | 빈 상태 | 모든 도메인 0건 | 동일 | 4개 카운트 모두 0 |
| STAT-N3 | 대량 데이터 | 상품 1000건 등록 | 동일 | productCount = 1000, 응답 1초 이내 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| STAT-E1 | 부서 데이터 존재 | 부서 5건 등록 | 동일 | 응답에 부서 수가 포함되지 않음 |
| STAT-E2 | 도메인 조회 실패 | 강제 예외 주입 | 동일 | 해당 항목만 0, 나머지 정상 |

## 4. 통합·회귀

- 상품·고객·직원·주문 등록/삭제 후 재호출 시 카운트가 즉시 반영되는지 확인.
- 운영 알림 API와 동일 컨트롤러 내에서 회귀 영향 없음을 확인.

## 5. 합격 기준

- 정상 TC 전 항목 통과
- 응답 시간 1초 이내, 50 동시 호출 안정
- 공통 API 응답 표준 준수
