# 주문 관리 - 주문 상태 관리 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 주문 상태 관리
**SDLC 단계:** 테스트

## 1. 테스트 범위

`PATCH /api/orders/{id}/status`의 모든 전이 케이스 + CANCELLED 시 재고 복원.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| STAT-N1 | 정방향 전이 | PENDING | PATCH → CONFIRMED | 200 |
| STAT-N2 | CANCELLED 전이 | PENDING (재고 차감 5) | PATCH → CANCELLED | 200, 재고 +5 복원 |
| STAT-N3 | 임의 전이 | DELIVERED | PATCH → PENDING | 200 (1차에선 허용) |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| STAT-E1 | enum 외 값 | "ZZZ" | PATCH | 400 |
| STAT-E2 | 동일 status로 PATCH | PENDING → PENDING | PATCH | 200 (변동 없음) |

## 4. 통합·회귀

- CANCELLED 전이 후 [[운영알림지표]]의 PENDING 카운트 감소 확인

## 5. 합격 기준

- enum 검증 100%, 재고 복원 정확
