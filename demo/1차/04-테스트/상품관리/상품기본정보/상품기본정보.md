# 상품 관리 - 상품 기본정보 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / 상품 기본정보
**SDLC 단계:** 테스트

## 1. 테스트 범위

상품 CRUD 5개 API의 정상·예외 동작과 응답 표준 준수를 검증한다.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| PROD-N1 | 등록 | 빈 DB | POST /api/products (정상값) | 201, id 발급 |
| PROD-N2 | 목록 | 상품 3건 | GET /api/products | 3건 반환 |
| PROD-N3 | 상세 | 등록된 id | GET /api/products/{id} | 200, 본문 정확 |
| PROD-N4 | 수정 | 등록된 id | PUT (가격 변경) | 200, 변경 반영 |
| PROD-N5 | 삭제 | 등록된 id | DELETE | 204, 재조회 시 404 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| PROD-E1 | 필수 누락 | name 없음 | POST | 400 |
| PROD-E2 | 음수 가격 | price=-100 | POST | 400 |
| PROD-E3 | 존재하지 않는 id | id=999 | GET | 404 |
| PROD-E4 | SKU 중복 | 동일 SKU 두 번 등록 | POST 두 번 | 둘 다 201 (1차에서는 허용) |

## 4. 통합·회귀

- 상품 삭제 후 해당 상품을 참조하는 주문이 보존되는지 확인
- 다른 도메인에서 상품 카운트가 정확한지

## 5. 합격 기준

- 정상 TC 전 항목 통과
- 응답 1초 이내, 응답 표준 준수
