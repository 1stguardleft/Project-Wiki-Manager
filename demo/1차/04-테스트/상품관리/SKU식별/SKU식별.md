# 상품 관리 - SKU 식별 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / SKU 식별
**SDLC 단계:** 테스트

## 1. 테스트 범위

상품 등록·수정 시 `sku` 필드 처리.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SKU-N1 | SKU 입력 | "MILK-1L" | POST 상품 | 201, 응답에 sku 포함 |
| SKU-N2 | 자유 문자열 | "임의문자_123!" | POST 상품 | 201 (검증 없음) |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SKU-E1 | SKU 누락 | sku 미입력 | POST | 400 |
| SKU-E2 | SKU 중복 | 동일 sku 두 상품 | POST 두 번 | 둘 다 201 (1차 허용) |

## 4. 통합·회귀

- 상품 상세 조회에 sku가 반영되는지 확인

## 5. 합격 기준

- 필수값 동작 정확
- 형식·중복 검증 없음 정책 일관
