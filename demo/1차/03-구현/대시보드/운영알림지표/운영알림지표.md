# 대시보드 - 운영 알림 지표 - 구현 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 운영 알림 지표
**SDLC 단계:** 구현

## 1. 구현 범위

DashboardController에 `/alerts` 엔드포인트 추가. OrderRepository · ProductRepository의 카운트 쿼리를 호출해 DTO로 묶는다.

## 2. 구현 항목 체크리스트

- [ ] `OrderRepository.countByStatus(OrderStatus.PENDING)` 추가
- [ ] `ProductRepository.countByQuantityLessThan(int)` 추가
- [ ] AlertsResponse DTO 정의 (2개 필드)
- [ ] DashboardController에 `GET /api/dashboard/alerts` 추가
- [ ] 단위 테스트 작성

## 3. 적용 기술

- Spring Data JPA derived query (`countByStatus`, `countByQuantityLessThan`)
- 공통 API 응답 표준 적용

## 4. 단계별 작업 순서

1. Repository 메서드 시그니처 정의 → 2. DTO → 3. Service → 4. Controller → 5. 테스트
