# 주문 관리 - 주문 처리 - 구현 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 주문 처리
**SDLC 단계:** 구현

## 1. 구현 범위

Order 엔티티/Service/Controller/Repository 신설. 등록 시 customer/product 존재 검증, totalAmount 계산, 재고 차감을 한 트랜잭션에서 처리.

## 2. 구현 항목 체크리스트

- [ ] Order 엔티티 정의
- [ ] OrderRepository 인터페이스
- [ ] OrderService: create / getAll / getById / delete
- [ ] @Transactional 적용
- [ ] customer/product 존재 검증
- [ ] DTO 분리 (OrderRequest / OrderResponse)
- [ ] 단위/통합 테스트

## 3. 적용 기술

- Spring Boot, JPA, @Transactional
- DTO 패턴

## 4. 단계별 작업 순서

1. Entity/Repo → 2. Service → 3. Controller → 4. 트랜잭션 검증 → 5. 테스트

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 동시 주문으로 재고 음수 | 1차 허용, 운영자 모니터링 |
| 트랜잭션 누락 | 통합 테스트로 보장 |

## 6. 검증 포인트

- 등록 시 재고 차감, totalAmount 정확성
- 삭제 시 재고 복원 안 되는 정책 일관
