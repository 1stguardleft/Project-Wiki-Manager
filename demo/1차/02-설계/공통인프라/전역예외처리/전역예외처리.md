# 공통/인프라 - 전역 예외 처리 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 공통/인프라 / 전역 예외 처리
**SDLC 단계:** 설계

## 1. 설계 개요

`@ControllerAdvice` 클래스 한 개로 모든 예외를 포착해 ApiResponse(success=false)로 변환한다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Advice | GlobalExceptionHandler | 예외 핸들러 |

## 3. 핸들러 매핑

| 예외 타입 | 응답 코드 |
|---|---|
| MethodArgumentNotValidException | 400 |
| ConstraintViolationException | 400 |
| 그 외 모든 예외 | 500 |

## 4. 설계 규칙

- 응답은 [[공통API응답]] 형태.
- 로그는 ERROR 레벨, stacktrace 포함.
- 1차에서는 errorCode/timestamp 미제공.
