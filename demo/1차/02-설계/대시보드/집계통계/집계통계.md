# 대시보드 - 집계 통계 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 집계 통계
**SDLC 단계:** 설계

## 1. 설계 개요

집계 통계는 별도 엔티티 없이 **각 도메인 Repository의 `count()` 호출 결과를 묶어** 단일 응답으로 반환하는 read-only 기능이다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | DashboardController | 집계 API 노출 |
| Service | DashboardService | 4개 도메인 count 합산 |
| Repository | ProductRepository / CustomerRepository / EmployeeRepository / OrderRepository | count() 제공 |

## 3. 데이터 / 항목

본 서브도메인은 자체 엔티티가 없다. 응답 DTO는 4개 정수 필드를 포함한다.

| 항목 | 타입 | 설명 |
|---|---|---|
| productCount | long | 상품 총 건수 |
| customerCount | long | 고객 총 건수 |
| employeeCount | long | 직원 총 건수 |
| orderCount | long | 주문 총 건수 |

## 4. 인터페이스 (API)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/dashboard/stats | 4개 도메인 카운트 일괄 조회 |

## 5. 처리 흐름

1. 클라이언트가 `/api/dashboard/stats` 호출
2. Service가 4개 Repository의 `count()`를 순차 호출
3. DTO에 담아 단일 응답 반환

## 6. 설계 규칙

- 캐시 없이 매 호출 시 실시간 카운트.
- 부서 수는 집계 대상이 아님.
- 응답 표준은 [[공통API응답]] 규약을 따른다.
