# 고객 관리 - 고객 검색 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 고객 관리 / 고객 검색
**SDLC 단계:** 설계

## 1. 설계 개요

1차에는 별도 검색 컴포넌트를 두지 않는다. 클라이언트는 전체 목록 API를 호출 후 자체 필터를 적용한다.

## 2. 구성 요소

해당 없음 (별도 컴포넌트 없음).

## 3. API 인터페이스

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/customers | (대용) 전체 목록을 받아 클라이언트가 필터 |

## 4. 설계 규칙

- 서버측 검색 미제공.
- 2차에서 본격 도입 시 인덱스/페이지네이션을 함께 설계 예정.
