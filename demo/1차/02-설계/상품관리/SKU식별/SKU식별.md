# 상품 관리 - SKU 식별 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / SKU 식별
**SDLC 단계:** 설계

## 1. 설계 개요

SKU는 Product 엔티티의 `sku` 컬럼으로 단순 보관한다. 별도 검증·인덱스 없이 NOT NULL 제약만 적용.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Entity | Product | sku 컬럼 보유 |
| Repository | ProductRepository | 기본 CRUD 활용 |

## 3. 데이터 모델

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| sku | varchar(60) | NOT NULL | 운영자 입력 식별자 |

## 4. API 인터페이스

본 서브도메인 전용 엔드포인트 없음(상품 CRUD에 포함).

## 5. 설계 규칙

- 형식 검증 없음 (자유 문자열).
- unique 제약 없음.
- 인덱스 없음(검색 시 풀스캔).
