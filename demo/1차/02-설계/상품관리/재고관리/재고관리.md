# 상품 관리 - 재고 관리 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / 재고 관리
**SDLC 단계:** 설계

## 1. 설계 개요

재고는 Product 엔티티의 `quantity` 컬럼으로 표현한다. 별도 재고 이력 테이블은 두지 않으며, low-stock 조회만 추가로 제공한다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | ProductController | low-stock 조회 |
| Service | ProductService | 재고 부족 필터링 |
| Repository | ProductRepository | findByQuantityLessThan |

## 3. 데이터 모델

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| quantity | int | default 0 | 현재 재고 |

(별도 이력 테이블 없음)

## 4. API 인터페이스

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/products/low-stock | 재고 부족 상품 목록 (임계값 10 고정) |

## 5. 처리 흐름

1. Service가 `findByQuantityLessThan(10)` 호출
2. 결과 리스트를 응답

## 6. 설계 규칙

- 임계값 10은 코드 상수.
- 재고 변경 시 이력 기록 없음.
- 임의 재고 조정 엔드포인트는 1차 범위 아님(주문 시 자동 변동에만 의존).
