# ERP-system 도메인 맵 (확정)

**문서 버전:** v1.0
**확정일:** 2026-05-28
**세분화 수준:** 2계층 (도메인 → 서브도메인), 공통/인프라 포함

모든 SDLC 단계 문서는 아래 도메인/서브도메인 구조를 기준으로 작성한다.
폴더 구조: `{차수} > {SDLC 단계} > {도메인} > {서브도메인} > xxx.md`

## 도메인 → 서브도메인

| 도메인 | 서브도메인 | 근거(코드/기능) |
|--------|-----------|----------------|
| 대시보드 | 집계 통계 | 상품/고객/직원/주문 건수 count |
| | 운영 알림 지표 | 접수 대기 주문 수, 재고 부족 상품 수(<10) |
| | 매출 집계 | 전체 주문 금액 합계 |
| 상품 관리 | 상품 기본정보 | 등록/조회/수정/삭제 CRUD |
| | 상품 분류 | `GET /api/products/category/{category}` |
| | 재고 관리 | 재고 부족 조회(`/low-stock`), 재고 조정(`PATCH /{id}/stock`) |
| | SKU 식별 | SKU unique 검증 |
| 고객 관리 | 고객 기본정보 | 등록/조회/수정/삭제 CRUD |
| | 고객 검색 | (추가 요구사항) 이름·전화번호 검색 |
| | 고객 변경 이력 | (추가 요구사항) 수정 이력 기록·조회 |
| 주문 관리 | 주문 처리 | 생성/조회/삭제 |
| | 주문 상태 관리 | 상태 5단계 전이, `PATCH /{id}/status` |
| | 주문 조회 필터 | 고객별/상태별 조회 |
| | 재고 연동 | 생성 시 재고 차감, 취소 시 복원 |
| | 금액 계산 | 가격 × 수량 자동 산출 |
| 직원 관리 | 직원 기본정보 | 등록/조회/수정/삭제 CRUD |
| | 부서 배치 | 부서별 조회, 부서 검증 |
| | 급여/인사 정보 | 급여, 직책, 입사일 |
| 부서 관리 | 부서 기본정보 | 등록/조회/수정/삭제 CRUD |
| 공통/인프라 | 공통 API 응답 | `ApiResponse` DTO |
| | 전역 예외 처리 | `GlobalExceptionHandler` |

## 도메인 아님 (제외)

- `ErpApplication` (부트스트랩)
- 인증/로그인/사용자(User) 도메인 — 코드에 미존재
  (요구사항 문서의 "사용자"는 업무 역할일 뿐 시스템 계정 도메인이 아님)

## 비고

- 상품 관리의 **재고 조정(`PATCH /api/products/{id}/stock`)** 기능은 기존 상품 요구사항 문서에서
  누락되어 있어 향후 `재고 관리` 서브도메인에 반영 필요.
