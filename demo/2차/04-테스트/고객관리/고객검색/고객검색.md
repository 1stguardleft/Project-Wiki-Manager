# 고객 관리 - 고객 검색 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 고객 관리 / 고객 검색
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** 검색 API 신규 검증.

## 1. 테스트 범위

`GET /api/customers/search`의 부분일치·페이지네이션·경계.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SRCH-N1 | 이름 부분일치 | "김민수","김지영","박철수" | ?name=김 | 2건 |
| SRCH-N2 | 전화 부분일치 | "010-1234-5678" 등 | ?phone=5678 | 매치 건만 |
| SRCH-N3 | 페이지네이션 | 20건 등록 | ?name=김&page=0&size=5 | 5건, totalPages=4 |
| SRCH-N4 | 대소문자 무시 | "Kim" 등록 | ?name=kim | 1건 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SRCH-E1 | 파라미터 없음 | - | /search | 400 |
| SRCH-E2 | size=200 | - | ?name=김&size=200 | size 100으로 클램프 |
| SRCH-E3 | 결과 0건 | - | ?name=없음 | 빈 content, totalElements=0 |

## 4. 통합·회귀

- 1차 전체 목록 API 호환
- 인덱스 사용 여부 EXPLAIN 확인

## 5. 합격 기준

- 정상 TC 100%
- 응답 1초 이내 (10만건 기준)
