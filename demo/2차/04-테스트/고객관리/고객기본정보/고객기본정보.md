# 고객 관리 - 고객 기본정보 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 고객 관리 / 고객 기본정보
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** UNIQUE 검증, 활성 주문 삭제 차단 검증.

## 1. 테스트 범위

CRUD + 신규 정책 (UNIQUE, 삭제 차단).

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| CUST-N1 | 등록 | - | POST | 201 |
| CUST-N2 | 삭제 (주문 없음) | - | DELETE | 204 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| CUST-E1 | 이메일 중복 | 동일 email 두 번 | POST | 두 번째 409 DUPLICATE_EMAIL |
| CUST-E2 | 이메일 형식 오류 | "abc@" | POST | 400 INVALID_EMAIL |
| CUST-E3 | 활성 주문 보유 삭제 | PENDING 주문 1건 | DELETE | 409 CUSTOMER_IN_USE |
| CUST-E4 | DELIVERED만 보유 삭제 | DELIVERED 주문 1건 | DELETE | 204 (활성 아님) |

## 4. 통합·회귀

- 1차 등록·조회·수정 호환
- 마이그레이션 후 중복 이메일 0건 확인

## 5. 합격 기준

- 정상/예외 TC 전 항목 통과
- 응답 0.5초 이내
