# 부서 관리 - 부서 기본정보 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 부서 관리 / 부서 기본정보
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** manager 검증, 삭제 차단 검증.

## 1. 테스트 범위

CRUD + manager 검증 + 삭제 차단.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| DEPT-N1 | manager 지정 | 부서 A에 김민수 소속 | PUT manager_id=김민수 | 200 |
| DEPT-N2 | 직원 0 부서 삭제 | 직원 없음 | DELETE | 204 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| DEPT-E1 | 다른 부서 manager | 부서 A에 부서 B 직원 지정 | PUT | 400 INVALID_MANAGER |
| DEPT-E2 | 직원 보유 부서 삭제 | 직원 1건 소속 | DELETE | 409 DEPARTMENT_IN_USE |
| DEPT-E3 | 부서명 중복 | 동일 name | POST | 409 DUPLICATE_NAME |

## 4. 통합·회귀

- 1차 케이스: 직원 보유 부서 삭제 → 1차는 204, 2차는 409 (정책 변경 안내)

## 5. 합격 기준

- 정상/예외 TC 100%
- 응답 0.5초 이내
