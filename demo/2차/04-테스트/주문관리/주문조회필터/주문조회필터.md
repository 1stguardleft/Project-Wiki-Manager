# 주문 관리 - 주문 조회 필터 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 주문 관리 / 주문 조회 필터
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** 통합 검색·페이지네이션·기간/직원 필터.

## 1. 테스트 범위

`/api/orders/search`의 다중 조건 조합, 페이지네이션, 1차 경로 호환성.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| FLT-N1 | 고객 + 상태 | 고객A의 PENDING 3건 | ?customerId=A&status=PENDING | 3건 |
| FLT-N2 | 기간 | 2026-05의 주문 5건 | ?from=2026-05-01&to=2026-05-31 | 5건 |
| FLT-N3 | 직원별 | empId=10 주문 7건 | ?employeeId=10 | 7건 |
| FLT-N4 | 페이지 | 25건, size=10 | ?page=1&size=10 | 10건, totalPages=3 |
| FLT-N5 | 1차 경로 호환 | - | /customer/{id} | 200 + Deprecation 헤더 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| FLT-E1 | from > to | - | ?from=2026-06&to=2026-05 | 400 INVALID_PERIOD |
| FLT-E2 | size 초과 | - | ?size=200 | 100으로 클램프 |
| FLT-E3 | 결과 0 | - | ?customerId=999 | 빈 content |

## 4. 통합·회귀

- 1차 단일 필터 호출 결과와 통합 검색의 동일 조건 결과 일치

## 5. 합격 기준

- 다중 조건 결합 정확
- 응답 1초 이내 (10만건)
