# 직원 관리 - 급여/인사 정보 - 요구사항 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 직원 관리 / 급여/인사 정보
**SDLC 단계:** 요구사항
**변경 요점 (vs 1차):** position enum 도입, salary 범위(최저시급 이상~최대 한도) 검증.

## 1. 개요

직책 입력 오타·자유텍스트로 인한 혼선을 막기 위해 position을 enum으로 표준화하고, salary 입력 오류(0원·억대 오타 등)를 차단한다.

## 2. 사용자 시나리오

- 인사 담당자가 직책을 드롭다운(STAFF/MANAGER/DIRECTOR/EXECUTIVE)에서 선택.
- 급여 입력 실수(예: 30000000000)는 즉시 거부.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 인사-01 | position enum | STAFF/MANAGER/DIRECTOR/EXECUTIVE (신규) | 필수 |
| 인사-02 | salary 범위 검증 | 1,000,000 ~ 200,000,000 (신규) | 필수 |
| 인사-03 | hireDate 검증 | 1년 미래까지만 허용 (신규) | 권장 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| position | 필수 | enum | 4종 중 하나 |
| salary | 선택 | 정수 (범위 검증) | 급여 |
| hireDate | 선택 | 날짜 | 입사일 |

## 5. 업무 규칙

- position은 enum 외 값 거부.
- salary 범위 외 입력 → 400.
- hireDate 1년 초과 미래 → 400.

## 6. 비기능 요구사항

- 검증 추가 지연 무시 가능 수준.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 잘못된 enum | 400 INVALID_POSITION |
| salary 범위 외 | 400 INVALID_SALARY |
