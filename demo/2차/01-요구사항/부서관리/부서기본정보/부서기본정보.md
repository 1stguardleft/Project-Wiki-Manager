# 부서 관리 - 부서 기본정보 - 요구사항 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 부서 관리 / 부서 기본정보
**SDLC 단계:** 요구사항
**변경 요점 (vs 1차):** 부서장(manager_id) 추가, 소속 직원 있는 부서 삭제 차단.

## 1. 개요

조직 구조 운영 품질을 높이기 위해 **부서장(manager) 개념을 도입**하고, 소속 직원이 있는 부서의 삭제를 차단한다.

## 2. 사용자 시나리오

- 인사 담당자가 영업팀에 김민수 직원을 부서장으로 지정한다.
- 매니저가 직원이 있는 부서를 삭제 시도 → 차단 안내.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 부서-01 | 등록/조회/수정/삭제 | CRUD 5종 | 필수 |
| 부서-02 | 부서장 지정 | manager_id 컬럼 (FK 직원) (신규) | 필수 |
| 부서-03 | 직원 보유 부서 삭제 차단 | 소속 직원 0건일 때만 삭제 (신규) | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| name | 필수 | UNIQUE | 부서명 |
| description | 선택 | 문자열 | 설명 |
| manager_id | 선택 | FK 직원 | 부서장 (2차 신규) |

## 5. 업무 규칙

- name UNIQUE 유지.
- manager_id는 해당 부서 소속 직원만 지정 가능.
- 직원 보유 부서 삭제 → 409.

## 6. 비기능 요구사항

- 응답 0.5초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 부서명 중복 | 409 DUPLICATE_NAME |
| 다른 부서 직원을 manager로 지정 | 400 INVALID_MANAGER |
| 직원 보유 부서 삭제 | 409 DEPARTMENT_IN_USE |
