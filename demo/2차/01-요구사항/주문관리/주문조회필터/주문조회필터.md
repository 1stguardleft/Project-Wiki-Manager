# 주문 관리 - 주문 조회 필터 - 요구사항 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 주문 관리 / 주문 조회 필터
**SDLC 단계:** 요구사항
**변경 요점 (vs 1차):** 기간 필터, 직원별 필터, 페이지네이션 추가.

## 1. 개요

기존 고객별·상태별 조회에 더해, 기간/직원 조건을 결합하고 페이지네이션을 지원하는 통합 검색 API를 제공한다.

## 2. 사용자 시나리오

- 매니저가 "이번 달 PENDING 주문"을 페이지별로 본다.
- 영업 매니저가 "김민수 직원이 등록한 지난 달 주문"을 모아 본다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 필터-01 | 고객별 | customerId 필터 | 필수 |
| 필터-02 | 상태별 | status 필터 | 필수 |
| 필터-03 | 기간 | from/to 필터 (신규) | 필수 |
| 필터-04 | 직원별 | employeeId 필터 (신규) | 필수 |
| 필터-05 | 페이지네이션 | page/size 지원 (신규) | 필수 |

## 4. 응답 정보

| 항목 | 설명 |
|---|---|
| content | 주문 목록 |
| totalElements / totalPages | 페이지 메타 |
| number / size | 현재 페이지/크기 |

## 5. 업무 규칙

- 모든 파라미터는 선택, 미지정 시 무필터(단, 결과 수 제한을 위해 size 기본 20).
- size 최대 100 (클램프).
- 기본 정렬: orderDate DESC.

## 6. 비기능 요구사항

- 조회 응답 1초 이내(인덱스 사용).

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| from > to | 400 INVALID_PERIOD |
| 잘못된 status | 400 |
