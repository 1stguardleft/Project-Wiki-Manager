# 주문 관리 - 금액 계산 - 요구사항 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 주문 관리 / 금액 계산
**SDLC 단계:** 요구사항
**변경 요점 (vs 1차):** 할인율 적용, 부가세 별도 계산, 응답 필드 분리.

## 1. 개요

실제 청구액(공급가 + 부가세)과 할인 금액을 분리해 산출함으로써, 매출/회계 리포트에서 사용할 수 있게 한다.

## 2. 사용자 시나리오

- 영업 담당자가 10% 할인을 적용해 주문을 등록하면 시스템이 자동으로 할인 금액과 부가세를 계산한다.
- 회계 담당자가 매출 리포트에서 공급가/부가세를 분리해 본다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 금액-01 | 자동 산출 | 단가 × 수량 - 할인 = 공급가 | 필수 |
| 금액-02 | 부가세 분리 | VAT 10% 별도 산출 (신규) | 필수 |
| 금액-03 | 할인율 적용 | discountRate (0~50%) 입력 가능 (신규) | 권장 |

## 4. 관리 정보

| 항목 | 형식 | 설명 |
|---|---|---|
| subtotal | 정수 | price × quantity |
| discountRate | 정수 (%) | 0~50, 기본 0 |
| discountAmount | 정수 | subtotal × discountRate / 100 |
| supplyAmount | 정수 | subtotal - discountAmount |
| vatAmount | 정수 | supplyAmount × 10% |
| totalAmount | 정수 | supplyAmount + vatAmount |

## 5. 업무 규칙

- 할인율 범위: 0~50%. 초과 입력 시 50%로 클램프.
- 부가세율 10% 고정.
- 모든 금액은 정수, 소수점 발생 시 절삭(floor).

## 6. 비기능 요구사항

- 계산 추가 지연 10ms 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 할인율 범위 초과 | 50%로 클램프 |
| price/quantity 누락 | 400 |
