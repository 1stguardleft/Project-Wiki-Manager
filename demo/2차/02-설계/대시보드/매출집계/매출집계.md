# 대시보드 - 매출 집계 - 설계 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 대시보드 / 매출 집계
**SDLC 단계:** 설계
**변경 요점 (vs 1차):** DELIVERED 상태 필터, 기간(from/to) 파라미터, 월 매출 분리.

## 1. 설계 개요

매출은 DELIVERED 주문의 totalAmount만 합산하며, 기간 필터 지원으로 임의 구간 매출 조회가 가능하다. 이번 달/지난 달 합계는 별도 필드로 함께 제공.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | DashboardController | `/api/dashboard/sales` 노출 |
| Service | DashboardService | 합계 계산 + 기간 분기 |
| Repository | OrderRepository | `sumByStatusAndOrderDateBetween(status, from, to)` |

## 3. 데이터 / 항목

| 항목 | 타입 | 설명 |
|---|---|---|
| totalSales | long | 기간 내 DELIVERED 합계 |
| currentMonthSales | long | 이번 달 DELIVERED 합계 |
| previousMonthSales | long | 지난 달 DELIVERED 합계 |
| from / to | date | 적용 기간 |

## 4. 인터페이스 (API)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/dashboard/sales?from=YYYY-MM-DD&to=YYYY-MM-DD | 매출 합계 |

## 5. 처리 흐름

1. from/to 파라미터 검증 (from ≤ to)
2. DELIVERED + 기간 조건 SUM 쿼리
3. 이번 달/지난 달 두 SUM 쿼리 추가
4. DTO 묶어 반환

## 6. 설계 규칙

- DELIVERED 외 상태는 합산에서 제외.
- 기간 미지정 시 from = epoch, to = 현재.
- 인덱스 권장: `(status, order_date)`.
