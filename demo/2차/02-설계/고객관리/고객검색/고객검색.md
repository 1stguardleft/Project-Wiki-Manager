# 고객 관리 - 고객 검색 - 설계 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 고객 관리 / 고객 검색
**SDLC 단계:** 설계
**변경 요점 (vs 1차):** Pageable 기반 검색 API 신설, 이름/전화번호 인덱스 추가.

## 1. 설계 개요

`GET /api/customers/search`를 신설하고 Spring Data의 `Pageable` + derived query로 부분일치 검색을 제공한다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | CustomerController | 검색 API 노출 |
| Service | CustomerService | 파라미터 검증 + 검색 호출 |
| Repository | CustomerRepository | `findByNameContainingIgnoreCaseOrPhoneContaining(name, phone, Pageable)` |

## 3. 데이터 모델

추가 컬럼 없음. 인덱스 추가:

- `idx_customer_name` (name)
- `idx_customer_phone` (phone)

## 4. API 인터페이스

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/customers/search?name=&phone=&page=&size= | 부분일치 검색 + 페이지네이션 |

## 5. 처리 흐름

1. 파라미터 검증 (둘 중 하나는 필수)
2. size 클램프 (1~100)
3. derived query 실행
4. Page<Customer> → CustomerSearchResponse 매핑

## 6. 설계 규칙

- LIKE는 양쪽 와일드카드 `%name%`.
- 대소문자 무시.
- 기본 정렬: createdAt DESC.
