# 상품 관리 - 상품 분류 - 구현 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 상품 관리 / 상품 분류
**SDLC 단계:** 구현
**변경 요점 (vs 1차):** category enum 도입, 마이그레이션 스크립트, categories 목록 API.

## 1. 구현 범위

ProductCategory enum 정의, Product 엔티티 컬럼 enum화, 기존 자유 텍스트를 enum으로 마이그레이션.

## 2. 구현 항목 체크리스트

- [ ] `enum ProductCategory { FOOD, BEVERAGE, HOUSEHOLD, ELECTRONICS, OTHER }` 정의
- [ ] Product 엔티티 컬럼 `@Enumerated(STRING)` 적용
- [ ] `findByCategory(ProductCategory)` 변경
- [ ] `GET /api/products/categories` 추가
- [ ] 마이그레이션 SQL: TRIM/UPPER 후 enum 매핑, 불일치 OTHER
- [ ] enum 외 값 → 400 변환

## 3. 적용 기술

- Java enum + JPA `EnumType.STRING`
- 마이그레이션 도구(Flyway 권장)

## 4. 단계별 작업 순서

1. enum 정의 → 2. 컬럼 enum 매핑 → 3. 마이그레이션 검토(기존 데이터 통계) → 4. 배포 후 마이그레이션 실행 → 5. 마이그레이션 결과 리포트

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 기존 데이터에 enum 외 값 다수 | OTHER로 일괄 매핑 + 운영자 리뷰 보고서 발행 |
| 클라이언트가 자유 텍스트 보냄 | API 400 응답 + 카테고리 목록 API로 안내 |

## 6. 검증 포인트

- 마이그레이션 후 카운트 검증(전체 = 5개 enum 합)
- 잘못된 enum 입력 → 400
