# 주문 관리 - 금액 계산 - 구현 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 주문 관리 / 금액 계산
**SDLC 단계:** 구현
**변경 요점 (vs 1차):** 4종 금액 컬럼 산출 + 할인율 클램프.

## 1. 구현 범위

OrderService.create의 금액 계산 로직을 4단계로 확장하고, Order 엔티티에 컬럼 추가.

## 2. 구현 항목 체크리스트

- [ ] DDL: subtotal/discountRate/discountAmount/supplyAmount/vatAmount/totalAmount
- [ ] 할인율 클램프(0~50)
- [ ] 4단계 계산 메서드 (단위 테스트 용이하게 분리)
- [ ] DTO에 discountRate 노출
- [ ] 마이그레이션: 기존 totalAmount를 supply/vat로 재산출 (or 그대로 보존, 신규 컬럼만 0으로 채움)

## 3. 적용 기술

- long 정수 연산 + floor
- DTO 검증(@Min/@Max)

## 4. 단계별 작업 순서

1. 컬럼 추가 → 2. 계산 메서드 → 3. DTO 적용 → 4. 마이그레이션 정책 → 5. 테스트

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 부가세율 변경 가능성 | 상수 → 외부화 후속 검토 |
| 기존 주문 데이터 재산출 정책 | 보존 + 신규부터 적용 권장 |

## 6. 검증 포인트

- 할인율 0/10/50 + 단가/수량 다양 케이스
- floor 처리 정확
