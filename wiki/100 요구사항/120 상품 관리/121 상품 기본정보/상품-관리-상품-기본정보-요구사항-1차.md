# 상품 관리 - 상품 기본정보 - 요구사항

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 상품 관리 / 상품 기본정보  
**SDLC 단계:** 요구사항  
**변경 요점 (vs 1차):** SKU unique 제약, 가격 0 이상 강화, 카테고리는 enum 사용, 삭제 시 사용 중인 상품 차단.

## 1. 개요

운영자가 회사가 취급하는 상품 마스터를 등록·조회·수정·삭제할 수 있어야 한다. 상품은 주문·재고·매출의 기준 데이터다. 상품 마스터 CRUD에 더해, **운영 품질을 떨어뜨리는 중복·삭제 사고를 막기 위한 검증**을 강화한다.

## 2. 사용자 시나리오

- 운영자가 신규 상품을 등록한다(이름·가격·SKU·카테고리·초기 재고).
- 영업 담당자가 전체 상품 목록을 조회해 가격을 확인한다.
- 매니저가 현재 진행 중인 주문에서 사용 중인 상품을 삭제하려 하면 차단 안내를 받는다.
- 운영자가 동일 SKU로 신규 상품을 등록하려 시도하면 차단된다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 상품-01 | 상품 등록 | 신규 상품 등록 | 필수 |
| 상품-02 | 상품 목록 조회 | 전체 목록 | 필수 |
| 상품-03 | 상품 상세 조회 | 단건 | 필수 |
| 상품-04 | 상품 수정 | 변경 | 필수 |
| 상품-05 | 상품 삭제 | 미사용 상품만 삭제 가능 | 필수 |
| 상품-06 | SKU 중복 검증 | 동일 SKU 등록 차단 (신규) | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| name | 필수 | 문자열 | 상품명 |
| price | 필수 | 정수 ≥ 0 | 가격 (음수 불가) |
| sku | 필수 | 형식 검증 | 식별자 (영문 대문자/숫자/하이픈) |
| category | 필수 | enum | FOOD / BEVERAGE / HOUSEHOLD / ELECTRONICS / OTHER |
| quantity | 선택 | 정수 ≥ 0 | 초기 재고 |
| description | 선택 | 문자열 | 설명 |

## 5. 업무 규칙

- SKU는 **시스템 전체에서 unique**.
- 가격은 0원 이상 (음수 불가).
- 카테고리는 정의된 enum 값만 허용.
- 진행 중인 주문(PENDING/CONFIRMED/SHIPPED)에서 참조 중인 상품은 삭제 불가 (1차에서는 강제 삭제, 연관 주문 보존).

## 6. 비기능 요구사항

- 등록·수정 응답 0.5초 이내.
- SKU 검증으로 인한 추가 부하 5% 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 필수 누락 | 400 오류 |
| SKU 중복 | 409, errorCode = DUPLICATE_SKU |
| 잘못된 카테고리 enum | 400, errorCode = INVALID_CATEGORY |
| 존재하지 않는 id 조회 | 404 오류 |
| 사용 중 상품 삭제 시도 | 409, errorCode = PRODUCT_IN_USE |
