# 대시보드 - 매출 집계 - 요구사항

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 대시보드 / 매출 집계  
**SDLC 단계:** 요구사항  
**변경 요점 (vs 1차):** 합산 대상을 DELIVERED 주문으로 제한, 기간(from/to) 필터, 월 매출 분리 응답 추가.

## 1. 개요

회계 기준에 맞춰 **확정 매출(DELIVERED 주문 합계)**만 집계해 대시보드/리포트에서 사용한다. 기간 필터로 임의 구간 매출 조회가 가능하다. 또한, 모든 주문의 금액 합계를 반환하여 전체 매출 상황을 파악할 수 있다.

## 2. 사용자 시나리오

- 회계 담당자가 이번 달 1일~말일 매출을 조회한다.  
- 경영진이 "이번 달 vs 지난 달" 매출 추이를 한 화면에서 확인한다.  
- 회계 담당자가 모든 주문의 금액 합계를 확인하여 전체 매출 상황을 파악한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 매출-01 | 확정 매출 합계 | DELIVERED 상태 주문만 합산 | 필수 |
| 매출-02 | 기간 필터 | `?from=YYYY-MM-DD&to=YYYY-MM-DD` 적용 | 필수 |
| 매출-03 | 월 매출 분리 응답 | 이번 달 / 지난 달 합계를 같이 반환 | 권장 |
| 매출-04 | 전체 주문 금액 합계 | 모든 주문의 totalAmount 합계를 반환 | 필수 |
| 매출-05 | 매출 합계 반환 | 매출 합계를 단일 숫자로 반환 | 필수 |

## 4. 응답 정보

| 항목 | 형식 | 설명 |
|---|---|---|
| totalSales | 정수(원) | 기간 내 DELIVERED 주문 합계 |
| currentMonthSales | 정수(원) | 이번 달 확정 매출 (2차 신규) |
| previousMonthSales | 정수(원) | 지난 달 확정 매출 (2차 신규) |
| totalAmount | 정수(원) | 모든 주문의 금액 합계 |
| from / to | 날짜 | 적용된 기간 |

## 5. 업무 규칙

- DELIVERED 외 상태(CANCELLED/PENDING 등)는 합산하지 않는다.  
- 기간 미지정 시 전체 기간 합계 + 이번 달/지난 달.  
- 주문 상태와 무관하게 모든 주문의 금액을 합산한다(취소 주문 포함).  
- 단위는 원, 소수점 없음.  
- 주문이 한 건도 없을 경우 `totalSales = 0`으로 반환한다.  
- 주문 도메인 조회 실패 시 `totalSales = -1`로 반환하고, 화면은 "조회 불가"로 표시한다.

## 6. 비기능 요구사항

- 응답 시간 1.5초 이내. 주문 수십만 건 환경에서도 안정 동작.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| from > to | 400 오류 (errorCode = INVALID_PERIOD) |
| 기간 내 주문 0건 | 합계 0으로 반환 (오류 아님) |
| 주문 도메인 조회 실패 | `totalSales = -1`, 화면은 "조회 불가" 표시 |

> ℹ️ 변경: 합산 대상을 DELIVERED 주문으로 제한했습니다. 이는 회계 기준에 맞춰 확정 매출만 집계하기 위한 것입니다.
