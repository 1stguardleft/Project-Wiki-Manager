# 직원 관리 - 직원 기본정보 - 요구사항

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 직원 관리 / 직원 기본정보  
**SDLC 단계:** 요구사항  
**변경 요점 (vs 1차):** email UNIQUE 적용, hire_date 미입력 시 등록일 자동 채움, 이메일 형식 검증 강화.

## 1. 개요

직원 마스터의 식별성을 높이기 위해 이메일을 unique로 격상하고, 입력 누락이 잦은 hire_date를 자동 보정한다.

## 2. 사용자 시나리오

- 인사 담당자가 동일 이메일로 두 번 등록하려 시도 → 차단.
- 신입 등록 시 hire_date를 빈 값으로 두면 등록일로 자동 채워진다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 직원-01 | 등록 | 신규 직원 등록 | 필수 |
| 직원-02 | 목록 | 전체 조회 | 필수 |
| 직원-03 | 상세 | 단건 조회 | 필수 |
| 직원-04 | 수정 | 정보 변경 | 필수 |
| 직원-05 | 삭제 | 직원 제거 | 필수 |
| 직원-06 | 이메일 UNIQUE | 동일 이메일 등록 차단 (신규) | 필수 |
| 직원-07 | hire_date 자동 | 미입력 시 등록일로 자동 채움 (신규) | 권장 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| email | 필수 | 이메일 형식, UNIQUE | 이메일 |
| (기타) | (1차 동일) | | |

## 5. 업무 규칙

- email은 시스템 전체 unique.
- hire_date 미입력 시 today() 적용.
- 이메일 형식 RFC 5322 기준.

## 6. 비기능 요구사항

- 등록 응답 0.5초 이내. UNIQUE 검증으로 인한 추가 부하 5% 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 이메일 중복 | 409 DUPLICATE_EMAIL |
| 이메일 형식 위반 | 400 |
