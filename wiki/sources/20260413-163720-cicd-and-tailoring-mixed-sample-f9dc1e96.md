# CI/CD 파이프라인과 프로젝트 테일러링 메모

## 요약
CI/CD 파이프라인에서 사용하는 대표 도구(Jenkins, Argo CD)와 프로젝트 테일러링 문서에 포함되는 스토리보드 산출물 기준을 함께 정리한 내부 메모다.

## 주요 내용

### CI/CD 파이프라인 도구
CI/CD 파이프라인은 빌드, 테스트, 배포를 자동화하는 흐름으로 구성된다.

#### Jenkins
- 전통적인 자동화 서버
- 빌드, 테스트, 패키징 작업을 파이프라인으로 구성 가능
- 플러그인을 통해 기능 확장 가능
- 온프레미스 환경이나 복잡한 커스텀 파이프라인이 필요한 경우에 사용

#### Argo CD
- GitOps 기반 배포 도구
- 애플리케이션 배포 상태를 Git 저장소 기준으로 동기화
- Kubernetes 환경에 적합
- 선언형 배포 운영과 배포 이력 추적이 필요한 경우 활용

#### 도구 선택 시 고려사항
- 빌드와 테스트 자동화 중심인지
- 배포 자동화와 운영 동기화 중심인지
- Kubernetes 기반 환경인지
- GitOps 운영 모델을 채택하는지

### 프로젝트 테일러링 문서와 스토리보드
프로젝트 상황에 맞게 산출물 유지/축소 여부를 정리하는 문서다.

#### 스토리보드 포함 여부
- 일정이 짧은 프로젝트: 핵심 화면만 작성
- 사용자 승인 절차가 중요한 프로젝트: 스토리보드 필수 산출물로 유지

#### 스토리보드 관련 결정 항목
- 모든 화면에 대해 스토리보드를 작성할지
- 핵심 화면만 작성할지
- 와이어프레임 수준으로 축소할지
- 화면 정의서를 별도 문서로 둘지

#### 테일러링 문서 내 기록 예시
- 핵심 업무 화면은 스토리보드 필수
- 단순 관리 화면은 목록 정의만 작성
- 공통 팝업은 별도 상세 스토리보드 생략 가능
- 변경 이력이 많은 화면은 리뷰 이력 포함

## 핵심 주장
- CI/CD 파이프라인 도구는 조직의 운영 방식과 배포 전략에 따라 달라질 수 있다
- Jenkins는 온프레미스 환경이나 복잡한 커스텀 파이프라인이 필요한 경우에 사용된다
- Argo CD는 GitOps 기반 배포 도구로 Kubernetes 환경에 적합하다
- 프로젝트 테일러링 문서에는 스토리보드 작성 여부와 수준이 포함될 수 있다
- 후속 정리 시 CI/CD 도구 관련 내용과 프로젝트 문서 기준 관련 내용을 분리해서 관리하는 것이 바람직하다
