# 상품 관리 - SKU 식별 - 테스트

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 상품 관리 / SKU 식별  
**SDLC 단계:** 테스트  
**변경 요점 (vs 1차):** UNIQUE 위반 검증, 정규식 검증, SKU 단건 조회.

## 1. 테스트 범위

SKU 형식·중복 검증, SKU 단건 조회, 마이그레이션 후 UNIQUE 무결성, 상품 등록·수정 시 `sku` 필드 처리.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SKU-N1 | 정상 형식 | "MILK-1L-001" | POST | 201 |
| SKU-N2 | SKU로 조회 | 등록된 SKU | GET /products/sku/{sku} | 200, 본문 정확 |
| SKU-N3 | SKU 변경 | 기존 sku → 새 sku | PUT | 200, 변경 반영 |
| SKU-N4 | SKU 입력 | "MILK-1L" | POST 상품 | 201, 응답에 sku 포함 |
| SKU-N5 | 자유 문자열 | "임의문자_123!" | POST 상품 | 201 (검증 없음) |
| SKU-N6 | SKU 중복 | 동일 sku 두 상품 | POST 두 번 | 둘 다 201 (1차 허용) |
| SKU-N7 | 상품 상세 조회 | 등록된 SKU | GET /products/{id} | 200, sku가 반영됨 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SKU-E1 | 너무 짧음 | "AB" | POST | 400 INVALID_SKU_FORMAT |
| SKU-E2 | 너무 김 | 31자 | POST | 400 |
| SKU-E3 | 한글 포함 | "우유-1L" | POST | 400 |
| SKU-E4 | 소문자 포함 | "milk-1l" | POST | 400 |
| SKU-E5 | 중복 | 동일 SKU 재등록 | POST | 409 DUPLICATE_SKU |
| SKU-E6 | 미존재 조회 | "ZZZ-999" | GET /sku/ZZZ-999 | 404 |
| SKU-E7 | SKU 누락 | sku 미입력 | POST | 400 |

## 4. 통합·회귀

- 마이그레이션 후 SKU UNIQUE 위반 0건
- 1차 등록 케이스(자유 SKU)는 모두 정상 매핑되거나 사전 정리됨

## 5. 합격 기준

- 형식·중복 검증 100%
- 단건 조회 응답 200ms 이내
