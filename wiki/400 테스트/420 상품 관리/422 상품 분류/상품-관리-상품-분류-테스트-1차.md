# 상품 관리 - 상품 분류 - 테스트

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 상품 관리 / 상품 분류  
**SDLC 단계:** 테스트  
**변경 요점 (vs 1차):** enum 검증, 카테고리 목록 API, 마이그레이션 결과 검증.

## 1. 테스트 범위

카테고리 enum 적용 후 조회/등록 동작, 카테고리 목록 API, 마이그레이션 후 정합성.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| CAT-N1 | enum 조회 | FOOD 3건 | GET /category/FOOD | 3건 |
| CAT-N2 | 카테고리 목록 | FOOD 3, BEVERAGE 2 | GET /products/categories | 5개 enum + OTHER |
| CAT-N3 | 마이그레이션 결과 | 기존 자유 텍스트 100건 | DB 조회 | 5개 enum 합 = 100건 |
| CAT-N4 | 카테고리 조회 | - | GET /api/products/category/{category} | 정확성과 입력 검증 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| CAT-E1 | 잘못된 enum | category="XYZ" | POST | 400 INVALID_CATEGORY |
| CAT-E2 | 소문자 | "food" 상품 3건 | GET /category/FOOD | 빈 배열. |
| CAT-E3 | 대소문자 구분 | category="food" | POST | 400 (enum 외 값) |

## 4. 통합·회귀

- 마이그레이션 전후 상품 카운트 일치
- 1차 클라이언트가 잘못된 카테고리 보내면 명확한 errorCode 반환
- 상품 카테고리 수정 후 양쪽 카테고리에 즉시 반영

## 5. 합격 기준

- enum 외 값 100% 거부
- 마이그레이션 후 데이터 손실 0
- 정확성 100%, 응답 1초 이내
