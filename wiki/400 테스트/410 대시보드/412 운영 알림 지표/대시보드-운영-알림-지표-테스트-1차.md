# 대시보드 - 운영 알림 지표 - 테스트

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 대시보드 / 운영 알림 지표  
**SDLC 단계:** 테스트  
**변경 요점 (vs 1차):** threshold 입력 검증, staleOrders 정확성. > ℹ️ 변경: 문서 버전이 v1.0에서 v2.0으로 업데이트되었습니다.

## 1. 테스트 범위

`GET /api/dashboard/alerts`의 세 지표 정확성, threshold 입력 폭 검증, 24시간 경계 정확성. > ℹ️ 변경: 테스트 범위가 확장되었습니다.

## 2. 정상 시나리오

| TC-ID    | 시나리오   | 전제                          | 실행               | 기대 결과               |
|----------|------------|-------------------------------|--------------------|-------------------------|
| ALERT-N1 | 기본 호출  | PENDING 3, 재고 9 상품 2, 24h↑ 1 | GET /alerts        | 3 / 2 / 1, threshold=10 |
| ALERT-N2 | threshold 20 | 재고 15 상품 1, 9 상품 2    | /alerts?threshold=20 | lowStockItems=3        |
| ALERT-N3 | stale 경계  | PENDING 23h59m 1건 + 24h01m 1건 | 기본 호출          | staleOrders=1          |
| ALERT-N4 | 재고 정확히 10 | PENDING 3, 재고 10 상품 1건 | 기본 호출          | pendingOrders=3, lowStockItems=2 |
| ALERT-N5 | 재고 0     | PENDING 0, 재고 0 상품 1건  | 기본 호출          | lowStockItems에 포함되지 않음(미만 기준) |

## 3. 경계·예외 시나리오

| TC-ID    | 시나리오         | 전제 | 실행                  | 기대 결과               |
|----------|------------------|------|-----------------------|-------------------------|
| ALERT-E1 | threshold=-5     | -    | /alerts?threshold=-5  | threshold=1 (클램프)    |
| ALERT-E2 | threshold=abc    | -    | /alerts?threshold=abc | threshold=10 (기본값)   |
| ALERT-E3 | threshold=99999  | -    | /alerts?threshold=99999 | threshold=1000 (클램프) |
| ALERT-E4 | quantity=10 상품 1건 | 재고 10 | 기본 호출          | lowStockItems에 포함되지 않음(미만 기준) |
| ALERT-E5 | quantity=0 상품 1건 | 재고 0 | 기본 호출          | lowStockItems에 포함    |

## 4. 통합·회귀

- 1차 응답 필드(pendingOrders, lowStockItems)가 그대로 호환되는지
- 주문 상태 변경 시 staleOrders 즉시 반영 > ℹ️ 변경: 통합·회귀 항목이 업데이트되었습니다.

## 5. 합격 기준

- 임계값 클램프 정책 일관 적용
- staleOrders 24시간 경계 ±1분 이내 정확
- 응답 1초 이내 > ℹ️ 변경: 합격 기준이 업데이트되었습니다.
