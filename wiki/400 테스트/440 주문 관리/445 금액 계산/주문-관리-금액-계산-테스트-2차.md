# 주문 관리 - 금액 계산 - 테스트

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 주문 관리 / 금액 계산  
**SDLC 단계:** 테스트  
**변경 요점 (vs 1차):** 할인·공급가·부가세·총액 분리 산출.

## 1. 테스트 범위

4단계 금액 산출의 정확성, 할인율 클램프, floor 처리.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| AMT-N1 | 기본 (할인 0) | price=10000, qty=3 | POST | subtotal=30000, supply=30000, vat=3000, total=33000 |
| AMT-N2 | 할인 10% | 위 + rate=10 | POST | discount=3000, supply=27000, vat=2700, total=29700 |
| AMT-N3 | 할인 50% | rate=50 | POST | discount=15000, supply=15000, vat=1500, total=16500 |
| AMT-N4 | floor | rate=3 → 30000*3/100=900 | POST | discount=900 정확 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| AMT-E1 | rate 초과 | rate=70 | POST | 50으로 클램프 |
| AMT-E2 | rate 음수 | rate=-5 | POST | 0으로 클램프 |
| AMT-E3 | price 0 | price=0 | POST | 모든 금액 0 |

## 4. 통합·회귀

- 1차 단순 totalAmount 케이스 (rate=0)에서 1차와 동일 결과
- 매출 집계가 supplyAmount 기준으로 정확

## 5. 합격 기준

- 4단계 계산 정확 100%
- floor 일관 적용
