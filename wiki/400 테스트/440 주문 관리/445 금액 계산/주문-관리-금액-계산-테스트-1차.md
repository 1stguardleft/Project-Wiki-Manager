# 주문 관리 - 금액 계산 - 테스트

## 1. 테스트 범위

등록 시 totalAmount 자동 산출의 정확성.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| AMT-N1 | 기본 산출 | price=10000, quantity=3 | POST | totalAmount=30000 |
| AMT-N2 | 단가 변경 후 신규 등록 | price 5000→6000 | POST 신규 | 신규는 6000 기준, 기존 주문 영향 없음 |
| AMT-N3 | 대량 곱셈 | price=999999, quantity=1000 | POST | long 범위 내 정확 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| AMT-E1 | quantity 누락 | - | POST | 400 |
| AMT-E2 | price 0 | 무료 상품 | POST | 201, totalAmount=0 |

## 4. 합격 기준

- 산출 정확 100%, 오버플로 0
