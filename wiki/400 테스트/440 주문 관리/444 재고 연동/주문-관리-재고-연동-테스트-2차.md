# 주문 관리 - 재고 연동 - 테스트

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 주문 관리 / 재고 연동  
**SDLC 단계:** 테스트  
**변경 요점 (vs 1차):** 재고 부족 거부, DELETE 복원, StockHistory 적재, 동시성.

## 1. 테스트 범위

등록 시 부족 거부, CANCELLED·DELETE 복원, StockHistory 적재 정확성, 동시성.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| INV-N1 | 등록 차감 + 이력 | quantity=10 | 주문 3 등록 | quantity=7, StockHistory(ORDER) 1건 |
| INV-N2 | CANCELLED 복원 + 이력 | 위 이어서 | CANCELLED 1건 | quantity=8, StockHistory(CANCEL) 1건 |
| INV-N3 | DELETE 복원 + 이력 | 위 이어서 | DELETE 1건 (status=PENDING) | quantity=9, StockHistory(CANCEL) 1건 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| INV-E1 | 재고 부족 | quantity=2 | 주문 5 등록 | 409 INSUFFICIENT_STOCK, 데이터 변동 없음 |
| INV-E2 | 동시 등록 | quantity=5, 동시 10건 | 동시 호출 | 5건 성공·5건 409, 최종 quantity=0 |
| INV-E3 | DELETE on CANCELLED | 이미 CANCELLED | DELETE | 204, 재고 추가 변동 없음 |

## 4. 통합·회귀

- 1차 등록 케이스(검증 없음)가 부족 시 409로 변경됨
- StockHistory 누락 0건

## 5. 합격 기준

- 음수 재고 0건
- 동시 호출 race 없음
