# 주문 관리 - 재고 연동 - 테스트

## 1. 테스트 범위

주문 등록 시 차감 / CANCELLED 시 복원의 정확성. 음수 재고 허용 동작.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| INV-N1 | 차감 | product.quantity=10 | 주문 3건(수량 3) 등록 | quantity=1 |
| INV-N2 | 복원 | 위 이어서 | 1건 CANCELLED | quantity=4 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| INV-E1 | 음수 재고 | quantity=2 | 주문 5 등록 | 201 + quantity=-3 (1차 허용) |
| INV-E2 | DELETE 시 미복원 | 주문 등록 후 삭제 | quantity 확인 | 차감 그대로 |

## 4. 합격 기준

- 등록·CANCELLED 변동 정확
- DELETE 시 미복원 정책 일관
