# 주문 관리 - 주문 상태 관리 - 테스트

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 주문 관리 / 주문 상태 관리  
**SDLC 단계:** 테스트  
**변경 요점 (vs 1차):** 전이 매트릭스 5×5 검증.

## 1. 테스트 범위

전이 규칙의 모든 케이스, CANCELLED 시 재고 복원.

## 2. 정상 시나리오 (허용 전이)

| TC-ID | from → to | 기대 결과 |
|---|---|---|
| TR-N1 | PENDING → CONFIRMED | 200 |
| TR-N2 | PENDING → CANCELLED | 200, 재고 복원 |
| TR-N3 | CONFIRMED → SHIPPED | 200 |
| TR-N4 | CONFIRMED → CANCELLED | 200, 재고 복원 |
| TR-N5 | SHIPPED → DELIVERED | 200 |
| STAT-N3 | DELIVERED → PATCH | 200 (1차에선 허용) |

> ℹ️ 변경: 정상 시나리오의 TC-ID 및 전이 규칙이 업데이트되었습니다. 기존의 TC-ID와 시나리오가 통합되었습니다.

## 3. 경계·예외 시나리오 (불허 전이)

| TC-ID | from → to | 기대 결과 |
|---|---|---|
| TR-E1 | DELIVERED → PENDING | 409 INVALID_TRANSITION |
| TR-E2 | SHIPPED → CANCELLED | 409 |
| TR-E3 | CANCELLED → PENDING | 409 |
| TR-E4 | DELIVERED → CANCELLED | 409 |
| TR-E5 | PENDING → SHIPPED | 409 (CONFIRMED를 거쳐야 함) |
| TR-E6 | enum 외 값 | 400 |

> ℹ️ 변경: 경계·예외 시나리오의 TC-ID 및 전이 규칙이 업데이트되었습니다. 기존의 예외 시나리오가 통합되었습니다.

## 4. 통합·회귀

- 1차 자유 전이 호출(예: DELIVERED → PENDING)이 409로 명확 응답
- CANCELLED 후 재고 복원 + StockHistory 적재
- CANCELLED 전이 후 [[운영알림지표]]의 PENDING 카운트 감소 확인

> ℹ️ 변경: 통합·회귀 항목이 업데이트되었습니다. 기존의 내용이 통합되었습니다.

## 5. 합격 기준

- 5×5 매트릭스 100% 통과
- CANCELLED 복원 정확

> ℹ️ 변경: 합격 기준이 업데이트되었습니다. 기존의 기준이 통합되었습니다.
