# 직원 관리 - 부서 배치 - 테스트

## 1. 테스트 범위

부서별 조회 + 부서 필수 검증.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| DEP-N1 | 부서별 조회 | 영업팀 직원 3, 개발팀 2 | GET /department/{영업팀.id} | 3건 |
| DEP-N2 | 부서 변경 | 직원 부서 변경 | PUT | 변경 반영 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| DEP-E1 | 미존재 부서 등록 | departmentId=999 | POST | 404 |
| DEP-E2 | departmentId 누락 | - | POST | 400 |
| DEP-E3 | 직원 0 부서 | 영업팀 직원 0 | GET | 빈 배열 |

## 4. 합격 기준

- 조회·검증 정확
- 응답 1초 이내
