# 고객 관리 - 고객 기본정보 - 테스트

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 고객 관리 / 고객 기본정보  
**SDLC 단계:** 테스트  
**변경 요점 (vs 1차):** UNIQUE 검증, 활성 주문 삭제 차단 검증. > ℹ️ 변경: 문서 버전이 v1.0에서 v2.0으로 업데이트되었습니다.

## 1. 테스트 범위

CRUD + 신규 정책 (UNIQUE, 삭제 차단). > ℹ️ 변경: 테스트 범위가 CRUD 5개 API에서 CRUD + 신규 정책으로 변경되었습니다.

## 2. 정상 시나리오

| TC-ID   | 시나리오         | 전제       | 실행       | 기대 결과 |
|---------|------------------|------------|------------|-----------|
| CUST-N1 | 등록             | -          | POST       | 201       |
| CUST-N2 | 목록             | 3건 등록   | GET        | 3건       |
| CUST-N3 | 상세             | id 보유    | GET /{id}  | 200       |
| CUST-N4 | 수정             | id 보유    | PUT        | 200       |
| CUST-N2 | 삭제 (주문 없음) | -          | DELETE     | 204       | > ℹ️ 변경: 정상 시나리오에서 삭제 시나리오가 추가되고, 목록 및 상세, 수정 시나리오가 삭제되었습니다.

## 3. 경계·예외 시나리오

| TC-ID   | 시나리오                   | 전제               | 실행          | 기대 결과                     |
|---------|----------------------------|--------------------|---------------|-------------------------------|
| CUST-E1 | 이메일 중복               | 동일 email 두 번   | POST          | 두 번째 409 DUPLICATE_EMAIL   | > ℹ️ 변경: 이메일 중복 등록 시나리오가 변경되었습니다. |
| CUST-E1 | 이메일 형식 위반          | "abc"              | POST          | 400                           | 
| CUST-E2 | 이메일 형식 오류          | "abc@"             | POST          | 400 INVALID_EMAIL             | > ℹ️ 변경: 이메일 형식 위반 시나리오가 변경되었습니다. |
| CUST-E2 | 필수 누락                 | name 없음          | POST          | 400                           |
| CUST-E3 | 이메일 중복 등록          | 동일 email         | POST 두 번    | 둘 다 201 (1차 허용)         |
| CUST-E3 | 활성 주문 보유 삭제       | PENDING 주문 1건   | DELETE        | 409 CUSTOMER_IN_USE           | > ℹ️ 변경: 활성 주문 보유 삭제 시나리오가 추가되었습니다. |
| CUST-E4 | DELIVERED만 보유 삭제     | DELIVERED 주문 1건 | DELETE        | 204 (활성 아님)               | > ℹ️ 변경: DELIVERED 주문 삭제 시나리오가 추가되었습니다. |

## 4. 통합·회귀

- 1차 등록·조회·수정 호환  
- 마이그레이션 후 중복 이메일 0건 확인 > ℹ️ 변경: 통합·회귀 항목이 업데이트되었습니다.

## 5. 합격 기준

- 정상/예외 TC 전 항목 통과  
- 응답 0.5초 이내 > ℹ️ 변경: 합격 기준이 정상 TC 100% 통과에서 정상/예외 TC 전 항목 통과로 변경되었습니다.
