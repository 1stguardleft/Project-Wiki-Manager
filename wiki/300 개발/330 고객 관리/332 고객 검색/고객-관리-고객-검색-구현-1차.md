# 고객 관리 - 고객 검색 - 구현

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 고객 관리 / 고객 검색  
**SDLC 단계:** 구현  
**변경 요점 (vs 1차):** 검색 API 신설, 인덱스 추가. > ℹ️ 변경: 문서 버전이 v1.0에서 v2.0으로 업데이트되었습니다.

## 1. 구현 범위

CustomerController에 `/search` 엔드포인트, Repository에 derived query, 인덱스 추가. 별도 구현 작업 없음. `GET /api/customers` 전체 목록 API만 활용. > ℹ️ 변경: 구현 범위가 전체 목록 API에서 검색 API로 변경되었습니다.

## 2. 적용 기술

- Spring Data Pageable + derived query
- DB 인덱스
- DTO 매핑 > ℹ️ 변경: 적용 기술이 추가되었습니다.

## 3. 위험 요소

| 위험 | 대응 |
|---|---|
| LIKE 양쪽 와일드카드로 인덱스 미사용 | 데이터 규모 모니터링, 필요 시 full-text 인덱스 도입 |
| 고객 수 증가 시 전체 조회 부하 | 2차에서 검색 API + 페이지네이션 도입 | > ℹ️ 변경: 위험 요소가 업데이트되었습니다.

## 4. 단계별 작업 순서

1. Repository 메서드 
2. DTO 
3. Service 검증 
4. Controller 
5. 인덱스 적용 
6. 테스트 > ℹ️ 변경: 단계별 작업 순서가 추가되었습니다.

## 5. 검증 포인트

- 이름/전화번호 단독·복합 조건
- 페이지 경계 (마지막 페이지 size 미만) > ℹ️ 변경: 검증 포인트가 추가되었습니다.
