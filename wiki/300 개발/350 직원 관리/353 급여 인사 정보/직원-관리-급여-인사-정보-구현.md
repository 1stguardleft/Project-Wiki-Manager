# 직원 관리 - 급여/인사 정보 - 구현

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 직원 관리 / 급여/인사 정보  
**SDLC 단계:** 구현  
**변경 요점 (vs 1차):** EmployeePosition enum, salary 범위 검증, hireDate 한도.

## 1. 구현 범위

EmployeePosition enum 정의, Employee.position 컬럼 enum화, salary/hireDate 검증 추가.

## 2. 구현 항목 체크리스트

- [ ] `enum EmployeePosition { STAFF, MANAGER, DIRECTOR, EXECUTIVE }`
- [ ] Employee.position `@Enumerated(STRING)` `@NotBlank`
- [ ] salary @Min(1000000) @Max(200000000) @Min(0) > ℹ️ 변경: salary 검증 범위가 0에서 1000000~200000000으로 변경되었습니다.
- [ ] hireDate 1년 미래 한도 검증  > ℹ️ 변경: hireDate 검증이 추가되었습니다.
- [ ] 마이그레이션: 기존 position 자유 텍스트 → STAFF 일괄 매핑
- [ ] 단위/통합 테스트

## 3. 적용 기술

- Bean Validation
- JPA enum

## 4. 단계별 작업 순서

1. enum 정의 
2. 컬럼 enum 매핑 
3. 검증 추가 
4. 마이그레이션 
5. 테스트

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 기존 자유텍스트 다수 | STAFF 매핑 + 운영자 정정 절차 |
| 직책 자유 텍스트로 분류 혼선 | 1차 허용, 2차 enum 검토 |  > ℹ️ 변경: 기존 위험 요소가 제거되고 새로운 위험 요소가 추가되었습니다.

## 6. 검증 포인트

- enum 외 → 400
- salary 범위 외 → 400
- hireDate 누락 거부  > ℹ️ 변경: hireDate 검증 포인트가 추가되었습니다.
