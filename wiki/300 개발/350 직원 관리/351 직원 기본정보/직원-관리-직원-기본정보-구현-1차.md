# 직원 관리 - 직원 기본정보 - 구현

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 직원 관리 / 직원 기본정보  
**SDLC 단계:** 구현  
**변경 요점 (vs 1차):** UNIQUE 마이그레이션, hire_date 자동 보정.

## 1. 구현 범위

DDL UNIQUE 적용, EmployeeService의 사전 검증 추가. Employee 엔티티/Service/Controller/Repository 신설 및 CRUD 5개 API 구현.

## 2. 구현 항목 체크리스트

- [ ] DDL: `ALTER TABLE employee ADD CONSTRAINT uk_employee_email UNIQUE(email)`
- [ ] 중복 정리 마이그레이션
- [ ] existsByEmail derived query
- [ ] hire_date null → LocalDate.now() 보정
- [ ] [[전역예외처리]]에 DUPLICATE_EMAIL 매핑
- [ ] 통합 테스트
- [ ] EmployeeService CRUD + 부서 존재 검증
- [ ] 이메일 형식 검증(@Email)
- [ ] DTO 분리
- [ ] 부서 미지정 → 400/404
- [ ] 이메일 형식 위반 → 400

## 3. 적용 기술

- Spring Boot, JPA, Bean Validation, 마이그레이션 도구
- LocalDate.now()

## 4. 단계별 작업 순서

1. 중복 보고서
2. 정리
3. UNIQUE 적용
4. Service 보정
5. 테스트

## 5. 위험 요소

| 위험               | 대응                          |
|-------------------|-------------------------------|
| 기존 중복 이메일  | 정리 후 UNIQUE 적용           |

## 6. 검증 포인트

- 중복 → 409
- hire_date 누락 시 등록일 자동
