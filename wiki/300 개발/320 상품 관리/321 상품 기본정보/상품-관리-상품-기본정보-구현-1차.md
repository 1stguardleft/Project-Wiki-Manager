# 상품 관리 - 상품 기본정보 - 구현

**문서 버전:** v1.0  
**도메인 / 서브도메인:** 상품 관리 / 상품 기본정보  
**SDLC 단계:** 구현  

## 1. 구현 범위

ProductController/Service/Entity/Repository를 신설해 상품 CRUD 5개 API를 제공한다.

## 2. 구현 항목 체크리스트

- [ ] Product 엔티티 정의 (8개 컬럼)
- [ ] ProductRepository 인터페이스 (JpaRepository 상속)
- [ ] ProductService.create/getAll/getById/update/delete
- [ ] ProductController 5개 엔드포인트
- [ ] 필수값/가격 음수 검증
- [ ] 단위 + 통합 테스트

## 3. 적용 기술

- Spring Boot 3.x, Spring Data JPA, Validation API
- DTO 분리 (ProductRequest / ProductResponse)
- 응답 표준은 [[공통API응답]] 적용

## 4. 단계별 작업 순서

1. Entity/Repository  
2. DTO  
3. Service  
4. Controller  
5. 단위 테스트  
6. 통합 테스트  

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 카테고리·SKU 중복으로 데이터 품질 저하 | 1차 범위에는 운영자 교육으로 대응 |
| 삭제 시 주문에서 상품 참조 깨짐 | 1차에서는 강제 삭제 허용, 추후 정책 검토 |

## 6. 검증 포인트

- 등록·조회·수정·삭제 정상 동작
- 음수 가격 거부
