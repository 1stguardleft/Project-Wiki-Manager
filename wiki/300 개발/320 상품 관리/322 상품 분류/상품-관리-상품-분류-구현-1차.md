# 상품 관리 - 상품 분류 - 구현

**문서 버전:** v1.0  
**도메인 / 서브도메인:** 상품 관리 / 상품 분류  
**SDLC 단계:** 구현  

## 1. 구현 범위

ProductRepository에 `findByCategory` 메서드, Controller에 `/category/{category}` 엔드포인트를 추가한다.

## 2. 구현 항목 체크리스트

- [ ] `findByCategory(String category)` derived query
- [ ] ProductController.findByCategory 추가
- [ ] 빈 카테고리 입력 거부
- [ ] 단위 테스트

## 3. 적용 기술

- Spring Data JPA derived query

## 4. 단계별 작업 순서

1. Repository 메서드  
2. Controller 핸들러  
3. 테스트  

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 카테고리 입력 오타로 분류 누락 | 1차 운영자 교육, 2차에 enum 도입 검토 |

## 6. 검증 포인트

- 동일 카테고리 상품이 모두 조회되는지
- 존재하지 않는 카테고리 → 빈 배열
