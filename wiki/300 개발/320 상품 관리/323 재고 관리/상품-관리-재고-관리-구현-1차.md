# 상품 관리 - 재고 관리 - 구현

**문서 버전:** v1.0  
**도메인 / 서브도메인:** 상품 관리 / 재고 관리  
**SDLC 단계:** 구현  

## 1. 구현 범위

ProductRepository에 low-stock 조회, ProductController에 엔드포인트 추가. 재고 변경은 주문 도메인에서 호출하며, 이력 보존은 하지 않는다.

## 2. 구현 항목 체크리스트

- [ ] `findByQuantityLessThan(int)` derived query
- [ ] ProductController에 `GET /low-stock` 핸들러
- [ ] 임계값 10 상수
- [ ] 단위 테스트

## 3. 적용 기술

- Spring Data JPA derived query

## 4. 단계별 작업 순서

1. Repository 메서드  
2. Controller  
3. 테스트  

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 이력 미보존으로 변동 원인 추적 불가 | 1차 범위 허용, 2차에서 StockHistory 검토 |
| 동시 주문 시 race condition | 1차에서는 트랜잭션 격리수준만 신뢰 |

## 6. 검증 포인트

- 임계값 미만 상품이 정확히 잡히는지
- 정확히 10인 상품은 제외되는지
