# 직원 관리 - 부서 배치 - 설계

## 1. 설계 개요

Employee.department_id를 NOT NULL FK로 두고, `EmployeeRepository.findByDepartmentId(deptId)`로 부서별 조회를 제공한다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | EmployeeController | 부서별 조회 API |
| Service | EmployeeService | 부서 존재 검증 |
| Repository | EmployeeRepository | findByDepartmentId |

## 3. 데이터 모델

| 컬럼 | 타입 | 제약 |
|---|---|---|
| department_id | bigint | FK, NOT NULL |

## 4. API 인터페이스

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/employees/department/{departmentId} | 부서별 직원 |

## 5. 처리 흐름

- 등록/수정: departmentId 존재 검증 → save
- 조회: derived query

## 6. 설계 규칙

- NOT NULL FK 제약.
- 부서 변경 이력 미보존.
