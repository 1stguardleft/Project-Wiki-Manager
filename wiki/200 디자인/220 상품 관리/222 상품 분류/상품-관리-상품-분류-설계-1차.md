# 상품 관리 - 상품 분류 - 설계

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 상품 관리 / 상품 분류  
**SDLC 단계:** 설계  
**변경 요점 (vs 1차):** 카테고리 enum 도입, 기존 데이터 마이그레이션, 카테고리 목록 API 신설.

## 1. 설계 개요

카테고리는 5종 enum(`FOOD`, `BEVERAGE`, `HOUSEHOLD`, `ELECTRONICS`, `OTHER`)으로 표준화하고, 1차의 자유 텍스트 데이터는 일회성 마이그레이션 스크립트로 매핑한다.

> ℹ️ 변경: 카테고리 enum 도입 및 기존 데이터 마이그레이션이 추가되었습니다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | ProductController | 카테고리 조회 / 목록 API |
| Service | ProductService | enum 검증 |
| Entity | Product | category enum 컬럼 |
| Repository | ProductRepository | findByCategory(enum) |

## 3. 데이터 모델

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| category | varchar(20) | NOT NULL | enum 5종 |

> ℹ️ 변경: category의 타입이 varchar(40)에서 varchar(20)으로 변경되었습니다.

## 4. API 인터페이스

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/products/category/{category} | 카테고리별 상품 (enum 값) |
| GET | /api/products/categories | 사용 가능 카테고리 enum 목록 (2차 신규) |

> ℹ️ 변경: 카테고리 목록 API가 신설되었습니다.

## 5. 처리 흐름

- 조회: 경로변수 enum 변환 시도 → 실패 시 400 → 성공 시 findByCategory
- 등록/수정: enum 검증 후 저장

> ℹ️ 변경: 처리 흐름에 enum 변환 및 검증 로직이 추가되었습니다.

## 6. 설계 규칙

- enum 외 값 거부.
- 마이그레이션 스크립트: TRIM + UPPER → 매핑표 → 불일치 OTHER.
- `category` 컬럼에 인덱스 추가.
- 카테고리별 조회는 `category` 동등 비교로 처리한다.
- 대소문자 구분 동등 비교.

> ℹ️ 변경: 카테고리 마스터 테이블 없음 및 대소문자 구분 동등 비교 규칙이 삭제되었습니다. 대신 `category` 컬럼에 인덱스가 추가되었습니다.
