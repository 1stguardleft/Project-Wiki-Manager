# 상품 관리 - 상품 기본정보 - 설계

**문서 버전:** v2.0  
**도메인 / 서브도메인:** 상품 관리 / 상품 기본정보  
**SDLC 단계:** 설계  
**변경 요점 (vs 1차):** sku UNIQUE, category enum 컬럼, 가격·재고 ≥ 0 DB 제약, 사용 중 상품 삭제 차단.

## 1. 설계 개요

CRUD 5종에 더해 SKU/카테고리 검증, 사용 중 상품 삭제 차단을 Service 레이어에 추가한다. SKU/카테고리 unique 제약은 두지 않는다.

## 2. 구성 요소

| 계층       | 구성 요소         | 역할               |
|------------|------------------|--------------------|
| Controller | ProductController | CRUD 노출          |
| Service    | ProductService    | unique/형식/사용 중 검증, 가격 음수 검증 |
| Entity     | Product           | category enum       |
| Repository | ProductRepository  | existsBySku, findBySku |

## 3. 데이터 모델

| 컬럼        | 타입          | 제약                                   | 설명     |
|-------------|---------------|----------------------------------------|----------|
| id          | bigint        | PK                                     |          |
| name        | varchar(120)  | NOT NULL                               |          |
| price       | bigint        | NOT NULL, CHECK ≥ 0                   |          |
| sku         | varchar(30)   | NOT NULL, UNIQUE                       |          |
| category    | varchar(20)   | NOT NULL, enum                         | FOOD/BEVERAGE/HOUSEHOLD/ELECTRONICS/OTHER |
| quantity    | int           | default 0, CHECK ≥ 0                   |          |
| description | varchar(500)  | nullable                               |          |
| created_at / updated_at | timestamp | 자동                             |

## 4. API 인터페이스

| 메서드 | 경로               | 설명                           |
|--------|-------------------|--------------------------------|
| POST   | /api/products      | 등록 (SKU/카테고리/가격 검증) |
| GET    | /api/products      | 목록                           |
| GET    | /api/products/{id} | 상세                           |
| GET    | /api/products/sku/{sku} | SKU로 단건 (2차 신규)   |
| PUT    | /api/products/{id} | 수정                           |
| DELETE | /api/products/{id} | 삭제 (사용 중 차단)           |

## 5. 처리 흐름

- 등록/수정: 형식 검증 → existsBySku 검증 → save  
- 삭제: 진행 중 주문(PENDING/CONFIRMED/SHIPPED) 참조 검사 → delete

## 6. 설계 규칙

- DB UNIQUE + Service 레벨 사전 검증으로 race condition 대비.  
- enum 값은 Java `@Enumerated(EnumType.STRING)`.  
- 응답 표준 [[공통API응답]] 준수.

## 7. 의존 서브도메인

| 연관 기능   | 의존 내용       |
|-------------|------------------|
| [[상품분류]] | enum 정의        |

| [[SKU식별]]  | UNIQUE + 형식    |

> ℹ️ 변경: SKU/카테고리 unique 제약이 추가되었고, 가격 및 재고에 대한 제약 조건이 강화되었습니다. 사용 중인 상품 삭제가 차단되는 규칙이 추가되었습니다. 가격 음수 검증은 Service 레이어에서 수행된다.
