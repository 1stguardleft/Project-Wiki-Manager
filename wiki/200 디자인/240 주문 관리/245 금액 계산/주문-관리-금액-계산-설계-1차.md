# 주문 관리 - 금액 계산 - 설계

**문서 버전:** v1.0  
**도메인 / 서브도메인:** 주문 관리 / 금액 계산  
**SDLC 단계:** 설계  

## 1. 설계 개요

OrderService.createOrder에서 단가 × 수량 → 할인 → 공급가 → 부가세 → 총액 순으로 계산하고, 각 단계 값을 Order 엔티티에 저장한다. 총액(totalAmount)은 product.price × order.quantity 공식을 일관되게 적용하여 산출한다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Service | OrderService | 금액 계산 메서드 |
| Entity | Order | 신규 컬럼 4종 |

## 3. 데이터 모델 (변경/신규)

| 컬럼 | 타입 | 제약 |
|---|---|---|
| subtotal | bigint | NOT NULL |
| discount_rate | int | default 0 (0~50) |
| discount_amount | bigint | NOT NULL |
| supply_amount | bigint | NOT NULL |
| vat_amount | bigint | NOT NULL |
| total_amount | bigint | NOT NULL |

## 4. 처리 흐름

1. subtotal = price × quantity  
2. discountAmount = subtotal × discountRate / 100 (floor)  
3. supplyAmount = subtotal - discountAmount  
4. vatAmount = supplyAmount × 10 / 100 (floor)  
5. totalAmount = supplyAmount + vatAmount  
6. 등록 트랜잭션 내 totalAmount 산출

## 5. 설계 규칙

- 모든 금액은 long(정수). 소수점 절삭.  
- 부가세율 10% 상수 (코드 상수, 추후 외부화 검토).  
- 할인율 클램프(0~50).
- 정수 연산을 통해 모든 계산이 이루어져야 한다.
