# 대시보드 - 집계 통계 - 요구사항 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 대시보드 / 집계 통계
**SDLC 단계:** 요구사항
**변경 요점 (vs 1차):** 부서 수 집계 추가, 응답 키를 `*Count` 형태로 통일, 엔드포인트 경로를 `/summary`로 명확화.

## 1. 개요

운영자의 일일 운영 화면에 핵심 마스터 데이터의 **현황 카운트**(상품·고객·직원·주문·부서)를 단일 호출로 묶어 보여 준다.

## 2. 사용자 시나리오

- 매니저가 한 화면에서 5개 도메인의 현황을 비교한다.
- 부서 수 증가/감소가 발생했을 때 동일 화면에서 확인한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 집계-01 | 전체 상품 수 | 상품 총 건수 반환 | 필수 |
| 집계-02 | 전체 고객 수 | 고객 총 건수 반환 | 필수 |
| 집계-03 | 전체 직원 수 | 직원 총 건수 반환 | 필수 |
| 집계-04 | 전체 주문 수 | 주문 총 건수 반환 | 필수 |
| 집계-05 | 전체 부서 수 | 부서 총 건수 반환 (신규) | 필수 |
| 집계-06 | 단일 응답 | 5개 카운트를 한 API로 반환 | 필수 |

## 4. 응답 정보

| 항목 | 형식 | 설명 |
|---|---|---|
| productCount | 정수 | 상품 총 건수 |
| customerCount | 정수 | 고객 총 건수 |
| employeeCount | 정수 | 직원 총 건수 |
| orderCount | 정수 | 주문 총 건수 |
| departmentCount | 정수 | 부서 총 건수 (신규) |

## 5. 업무 규칙

- 삭제된 레코드는 카운트에서 제외한다.
- 응답 형식은 공통 API 응답 표준을 따른다.
- 모든 카운트는 실시간 조회(캐시 없음).

## 6. 비기능 요구사항

- 응답 시간 1초 이내, 동시 호출 100건까지 안정.

## 7. 예외 처리
