# 상품 관리 - 상품 분류 - 요구사항 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 상품 관리 / 상품 분류
**SDLC 단계:** 요구사항
**변경 요점 (vs 1차):** 카테고리를 자유 텍스트에서 **enum**으로 전환, 카테고리 마스터 정의.

## 1. 개요

분류 누락·오타 문제를 방지하기 위해 카테고리를 5종 enum으로 표준화한다. 기존 자유 텍스트 데이터는 마이그레이션으로 매핑한다.

## 2. 사용자 시나리오

- 운영자가 신규 상품 등록 시 드롭다운에서 카테고리를 선택한다.
- MD가 정의된 5개 카테고리별 매출 비교 리포트를 만든다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 분류-01 | 카테고리별 조회 | enum 값별 상품 목록 | 필수 |
| 분류-02 | 카테고리 enum 정의 | FOOD/BEVERAGE/HOUSEHOLD/ELECTRONICS/OTHER | 필수 |
| 분류-03 | 카테고리 목록 조회 | 사용 가능한 카테고리 enum 반환 (신규) | 권장 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| category | 필수 | enum | 5개 중 하나 |

## 5. 업무 규칙

- 카테고리는 enum 외 값 거부.
- 기존 자유 텍스트(`food`, `FOOD `, `Food` 등)는 마이그레이션 시 대문자·trim으로 정규화 후 매핑.
- 매핑 실패는 OTHER로 분류.

## 6. 비기능 요구사항

- 카테고리별 조회 응답 1초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| enum 외 카테고리 입력 | 400, errorCode = INVALID_CATEGORY |
| 카테고리 목록 조회 | 항상 200, 5개 + OTHER 반환 |
