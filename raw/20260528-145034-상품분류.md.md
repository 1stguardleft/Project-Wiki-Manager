# 상품 관리 - 상품 분류 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / 상품 분류
**SDLC 단계:** 설계

## 1. 설계 개요

분류는 Product 엔티티의 `category` 컬럼 하나로 관리하며, 별도 분류 마스터 테이블은 두지 않는다. 카테고리별 조회는 `category` 동등 비교로 처리한다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | ProductController | 카테고리 조회 API |
| Service | ProductService | 카테고리 필터링 |
| Repository | ProductRepository | findByCategory |

## 3. 데이터 모델

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| category | varchar(40) | NOT NULL | 자유 문자열 |

## 4. API 인터페이스

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/products/category/{category} | 카테고리별 상품 목록 |

## 5. 처리 흐름

1. 경로변수 `category` 추출
2. `productRepository.findByCategory(category)`
3. 결과를 응답 표준에 맞춰 반환

## 6. 설계 규칙

- 대소문자 구분 동등 비교.
- 카테고리 마스터 테이블 없음.
- 분류별 인덱스 미적용(1차 범위).
