# 주문 관리 - 재고 연동 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 재고 연동
**SDLC 단계:** 설계

## 1. 설계 개요

주문 등록·CANCELLED 전이 시 상품 quantity를 자동 변동시키되, 재고 부족 검증은 하지 않는다(음수 재고 허용).

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Service | OrderService ↔ ProductService | 주문 흐름에서 재고 변동 호출 |

## 3. 처리 흐름

- 등록: `product.quantity -= order.quantity` (검증 없음)
- CANCELLED 전이: `product.quantity += order.quantity`
- 주문 삭제: 변동 없음

## 4. 설계 규칙

- 모든 변동은 등록/상태변경 트랜잭션 내에서 처리.
- 동시성은 트랜잭션 격리수준에만 의존.
- 재고 부족 검증 없음(1차 범위).
