# 상품 관리 - 상품 분류 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / 상품 분류
**SDLC 단계:** 요구사항

## 1. 개요

상품을 카테고리로 묶어 조회할 수 있도록 한다. 카테고리는 상품 등록 시 자유 텍스트로 입력하고, 동일 카테고리 문자열을 가진 상품끼리 그룹핑한다.

## 2. 사용자 시나리오

- MD가 "FOOD" 카테고리 상품만 모아 가격을 비교한다.
- 운영자가 "BEVERAGE" 카테고리의 재고 현황을 점검한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 분류-01 | 카테고리별 조회 | 특정 카테고리 상품 목록 반환 | 필수 |
| 분류-02 | 카테고리 자유 입력 | 등록/수정 시 자유 텍스트로 입력 | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| category | 필수 | 문자열 | 카테고리 식별자 |

## 5. 업무 규칙

- 카테고리는 대소문자 구분(`food` ≠ `FOOD`).
- 분류 마스터 테이블은 두지 않음(상품의 category 컬럼만).
- 빈 카테고리 입력은 허용하지 않는다.

## 6. 비기능 요구사항

- 카테고리별 조회 응답 1초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 존재하지 않는 카테고리 조회 | 빈 배열 반환 (오류 아님) |
| 빈 카테고리 등록 | 400 오류 |
