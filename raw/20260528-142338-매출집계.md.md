# 대시보드 - 매출 집계 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 매출 집계
**SDLC 단계:** 요구사항

## 1. 개요

대시보드 상단의 핵심 지표 중 하나로, **전체 주문의 금액 합계**를 단일 수치로 노출해 매출 규모를 한눈에 보여 준다.

## 2. 사용자 시나리오

- 경영진이 매일 아침 대시보드를 열어 누적 매출 합계를 확인한다.
- 매니저가 보고용 자료에 현재 매출 수치를 인용한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 매출-01 | 전체 매출 합계 | 모든 주문의 totalAmount 합계를 반환 | 필수 |
| 매출-02 | 단일 응답 | 매출 합계를 단일 숫자로 반환 | 필수 |

## 4. 응답 정보

| 항목 | 형식 | 설명 |
|---|---|---|
| totalSales | 정수(원) | 전체 주문 금액 합계 |

## 5. 업무 규칙

- 주문 상태와 무관하게 **모든 주문**의 금액을 합산한다(취소 주문 포함).
- 단위는 원, 소수점 없음.

## 6. 비기능 요구사항

- 응답 시간 1.5초 이내. 주문이 수만 건 누적되어도 안정 동작해야 함.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 주문이 한 건도 없음 | totalSales = 0 |
| 주문 도메인 조회 실패 | totalSales = -1, 화면은 "조회 불가" 표시 |
