# 대시보드 - 집계 통계 - 구현 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 집계 통계
**SDLC 단계:** 구현

## 1. 구현 범위

DashboardController + DashboardService를 신설하고, 4개 도메인의 Repository.count()를 호출해 응답 DTO로 묶는 흐름까지.

## 2. 구현 항목 체크리스트

- [ ] DashboardController 신설 (`GET /api/dashboard/stats`)
- [ ] DashboardService 신설 (4개 Repository 주입)
- [ ] StatsResponse DTO 정의 (4개 필드)
- [ ] 공통 API 응답 표준 적용
- [ ] 컨트롤러 단위 테스트 작성

## 3. 적용 기술

- Spring Boot Web Layer
- Spring Data JPA `count()`
- DTO 패턴(엔티티 미노출)

## 4. 단계별 작업 순서

1. DTO 정의 → 2. Service 메서드 작성 → 3. Controller 추가 → 4. 단위 테스트 → 5. 통합 검증

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 도메인이 늘어나면 매번 코드 수정 필요 | 1차에서는 4개로 고정, 확장은 추후 검토 |
| count() 합산이 무거워질 가능성 | 데이터 규모가 작아 1차에선 문제 없음 |

## 6. 검증 포인트

- 빈 DB 상태에서 모든 카운트가 0으로 반환되는지
- 한 도메인 추가/삭제 시 카운트 변동이 즉시 반영되는지
