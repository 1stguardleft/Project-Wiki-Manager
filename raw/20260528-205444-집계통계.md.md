# 대시보드 - 집계 통계 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 대시보드 / 집계 통계
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** 부서 카운트 검증 추가, deprecated 경로 동작 확인.

## 1. 테스트 범위

`GET /api/dashboard/summary`의 5개 카운트 정확성, 1차 `/stats` 호환성, 응답 표준 준수.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SUM-N1 | 5개 카운트 | 각 도메인 1건씩 + 부서 1건 | GET /summary | 5개 모두 1 |
| SUM-N2 | 빈 상태 | 모두 0건 | 동일 | 5개 모두 0 |
| SUM-N3 | 부서만 증감 | 부서 3건 등록·1건 삭제 | 동일 | departmentCount=2 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SUM-E1 | 도메인 조회 실패 | 강제 예외 | 동일 | 해당 항목 -1, 나머지 정상 |
| SUM-E2 | 1차 경로 호환 | `/stats` 호출 | GET /stats | 4개 카운트 응답 + `Deprecation` 헤더 |

## 4. 통합·회귀

- `/stats`와 `/summary`가 공통 4개 필드는 동일 값
- 부서 등록/삭제 후 즉시 반영

## 5. 합격 기준

- 정상·경계 TC 전 항목 통과
- 응답 시간 1초, 동시 호출 100 안정
- `/stats` 한 릴리스 유지 정책 확인
