# 상품 관리 - 상품 기본정보 - 구현 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 상품 관리 / 상품 기본정보
**SDLC 단계:** 구현
**변경 요점 (vs 1차):** SKU UNIQUE, category enum, 가격·재고 ≥ 0, 사용 중 삭제 차단.

## 1. 구현 범위

ProductService에 SKU/카테고리/사용 중 검증을 추가하고, Entity에 enum 컬럼·CHECK 제약을 도입.

## 2. 구현 항목 체크리스트

- [ ] Product 엔티티에 `@Enumerated(STRING)` 카테고리, UNIQUE sku 적용
- [ ] DB 마이그레이션: UNIQUE 인덱스 + CHECK 제약
- [ ] `existsBySku` derived query
- [ ] 사용 중 상품 검사 메서드(`existsByProductIdAndStatusIn`)
- [ ] DELETE 시 PRODUCT_IN_USE 예외
- [ ] DTO 검증(@NotBlank, @Min, @Pattern)
- [ ] 통합 테스트

## 3. 적용 기술

- Bean Validation
- JPA Enum
- Flyway/Liquibase 마이그레이션 가이드

## 4. 단계별 작업 순서

1. enum/제약 정의 → 2. 사전 검증 로직 → 3. 삭제 정책 → 4. 통합 테스트 → 5. 마이그레이션

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 기존 SKU 중복 데이터 | 마이그레이션 전 정리 스크립트로 dedupe |
| enum 값 변경 시 호환성 | enum 추가는 OK, 제거는 deprecation 거쳐 진행 |

## 6. 검증 포인트

- UNIQUE 위반이 409 + DUPLICATE_SKU로 변환되는지
- 진행 중 주문이 있는 상품 DELETE → 409
