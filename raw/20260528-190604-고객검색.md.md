# 고객 관리 - 고객 검색 - 요구사항 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 고객 관리 / 고객 검색
**SDLC 단계:** 요구사항
**변경 요점 (vs 1차):** 검색 API 신설 — 이름·전화번호 부분일치 검색 + 페이지네이션.

## 1. 개요

운영자가 고객 수가 늘어도 빠르게 특정 고객을 찾을 수 있도록 **이름·전화번호 부분일치 검색 API**를 제공한다.

## 2. 사용자 시나리오

- 영업 담당자가 "김"을 입력해 김씨 고객 목록을 5건씩 페이지 단위로 조회한다.
- 운영자가 전화번호 끝 4자리로 고객을 찾는다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 검색-01 | 이름 부분일치 | `?name=김` 으로 검색 | 필수 |
| 검색-02 | 전화번호 부분일치 | `?phone=1234` 으로 검색 | 필수 |
| 검색-03 | 페이지네이션 | `?page=0&size=20` 지원 | 필수 |
| 검색-04 | 결과 정렬 | 등록일 내림차순 기본 | 권장 |

## 4. 응답 정보

| 항목 | 설명 |
|---|---|
| content | 고객 요약 리스트 (id, name, email, phone) |
| totalElements | 전체 결과 수 |
| totalPages | 전체 페이지 수 |
| number / size | 현재 페이지/페이지 크기 |

## 5. 업무 규칙

- 이름/전화 둘 다 미지정 → 400.
- 부분일치(LIKE) 대소문자 무시.
- 최대 페이지 size 100 (초과 시 100으로 클램프).

## 6. 비기능 요구사항

- 검색 응답 1초 이내(10만 건 기준, 인덱스 가정).

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 두 파라미터 모두 없음 | 400 |
| size 범위 초과 | 100으로 클램프 |
