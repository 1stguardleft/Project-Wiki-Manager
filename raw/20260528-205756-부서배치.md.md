# 직원 관리 - 부서 배치 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 직원 관리 / 부서 배치
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** nullable, unassigned, 이력 적재.

## 1. 테스트 범위

미배치 등록, 부서 변경 이력 적재.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| DEP-N1 | 미배치 등록 | departmentId null | POST | 201, /unassigned에 포함 |
| DEP-N2 | 부서 배치 (null → A) | - | PUT | 이력 1건(from=null, to=A) |
| DEP-N3 | 부서 변경 (A → B) | - | PUT | 이력 1건(from=A, to=B) |
| DEP-N4 | 이력 조회 | 위 시점 | GET /department-history | 2건 |

## 3. 경계·예외 시나리오

|---|---|---|---|---|

| DEP-E2 | 미존재 부서 | departmentId=999 | PUT | 404 |
