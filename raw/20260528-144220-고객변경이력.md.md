# 고객 관리 - 고객 변경 이력 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 고객 관리 / 고객 변경 이력
**SDLC 단계:** 설계

## 1. 설계 개요

1차에는 변경 이력 컴포넌트를 두지 않는다. Customer 엔티티의 `updated_at` 컬럼만 갱신한다.

## 2. 구성 요소

해당 없음.

## 3. 데이터 모델

| 컬럼 | 타입 | 제약 |
|---|---|---|
| updated_at | timestamp | 자동 갱신 |

## 4. 설계 규칙

- 별도 이력 테이블 없음.
- 변경 전 값은 보존되지 않음.
