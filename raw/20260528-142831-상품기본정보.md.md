# 상품 관리 - 상품 기본정보 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / 상품 기본정보
**SDLC 단계:** 요구사항

## 1. 개요

운영자가 회사가 취급하는 상품 마스터를 등록·조회·수정·삭제할 수 있어야 한다. 상품은 주문·재고·매출의 기준 데이터다.

## 2. 사용자 시나리오

- 운영자가 신규 상품을 등록한다(이름·가격·SKU·카테고리·초기 재고).
- 영업 담당자가 전체 상품 목록을 조회해 가격을 확인한다.
- 매니저가 단종된 상품을 삭제한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 상품-01 | 상품 등록 | 신규 상품을 등록 | 필수 |
| 상품-02 | 상품 목록 조회 | 전체 상품 목록 | 필수 |
| 상품-03 | 상품 상세 조회 | id로 단건 조회 | 필수 |
| 상품-04 | 상품 수정 | 가격·이름 등 변경 | 필수 |
| 상품-05 | 상품 삭제 | 상품을 제거 | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| name | 필수 | 문자열 | 상품명 |
| price | 필수 | 정수(원) | 판매가 |
| sku | 필수 | 문자열 | 재고 식별자 |
| category | 필수 | 문자열 | 카테고리 |
| quantity | 선택 | 정수 | 초기 재고 |
| description | 선택 | 문자열 | 설명 |

## 5. 업무 규칙

- 필수 항목 누락 시 등록 불가.
- 가격은 음수 불가.
- SKU 중복은 허용 (1차 범위 내 검증 안 함).
- 카테고리는 자유 문자열로 입력 가능.

## 6. 비기능 요구사항

- 상품 목록 조회 응답 1초 이내(1만 건 기준).
- 등록·수정 트랜잭션 0.5초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 필수 누락 | 400 오류 |
| 존재하지 않는 id 조회 | 404 오류 |
| 삭제 시 진행 중 주문에서 참조 | 1차에서는 강제 삭제(연관 주문 보존) |
