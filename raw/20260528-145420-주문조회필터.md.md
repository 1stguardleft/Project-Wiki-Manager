# 주문 관리 - 주문 조회 필터 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 주문 조회 필터
**SDLC 단계:** 설계

## 1. 설계 개요

`findByCustomerId`, `findByStatus` 두 derived query를 추가해 단순 필터 조회를 제공한다.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Controller | OrderController | 필터 API |
| Repository | OrderRepository | findByCustomerId, findByStatus |

## 3. API 인터페이스

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /api/orders/customer/{customerId} | 고객별 |
| GET | /api/orders/status/{status} | 상태별 |

## 4. 처리 흐름

1. 경로변수 받음
2. Repository derived query 호출
3. 결과 반환

## 5. 설계 규칙

- 페이지네이션 미적용.
- 기간 필터 미적용.
- 결과 정렬은 DB 기본(등록순).
