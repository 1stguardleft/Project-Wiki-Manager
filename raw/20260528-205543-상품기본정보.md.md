# 상품 관리 - 상품 기본정보 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 상품 관리 / 상품 기본정보
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** SKU UNIQUE/형식, category enum, 사용 중 삭제 차단 검증 추가.

## 1. 테스트 범위

상품 CRUD + 2차 신규 정책(SKU/카테고리/삭제 차단) 검증.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| PROD-N1 | 등록 (정상 SKU/카테고리) | - | POST /products | 201 |
| PROD-N2 | 사용 중 아닌 상품 삭제 | 주문 참조 없음 | DELETE | 204 |
| PROD-N3 | 카테고리 enum 등록 | category=FOOD | POST | 201 |
| PROD-N4 | SKU로 단건 조회 | 등록된 sku | GET /products/sku/{sku} | 200 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| PROD-E1 | SKU 중복 | 동일 sku 두 번 | POST 두 번 | 두 번째 409 DUPLICATE_SKU |
| PROD-E2 | 잘못된 카테고리 | category="WRONG" | POST | 400 INVALID_CATEGORY |
| PROD-E3 | 음수 가격 | price=-1 | POST | 400 |
| PROD-E4 | 사용 중 상품 삭제 | 진행 중 주문 참조 | DELETE | 409 PRODUCT_IN_USE |
| PROD-E5 | SKU 형식 위반 | sku="ab" / 한글 / 소문자 | POST | 400 INVALID_SKU_FORMAT |

## 4. 통합·회귀

- 1차 기능(등록/조회/수정)이 그대로 호환되는지
- 진행 중 주문이 DELIVERED로 전이되면 상품 삭제 가능해지는지

## 5. 합격 기준

- 정상/예외 TC 전 항목 통과
- 응답 1초 이내, errorCode 표준 준수
