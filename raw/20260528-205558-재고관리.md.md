# 상품 관리 - 재고 관리 - 테스트 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 상품 관리 / 재고 관리
**SDLC 단계:** 테스트
**변경 요점 (vs 1차):** StockHistory 이력 적재, 재고 조정 API, threshold 파라미터, 음수 차단.

## 1. 테스트 범위

재고 조정·주문·취소 시 이력 적재 정확성, 동시 호출 race condition, 음수 차단, threshold 동작.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| STK-N1 | 재고 조정 | quantity=10 | PATCH /stock delta=+5 memo="실측조정" | quantity=15, StockHistory 1건(ADJUST) |
| STK-N2 | 주문 시 차감 + 이력 | quantity=10 | 주문 3건 등록 | quantity=7, StockHistory(ORDER) 1건 |
| STK-N3 | 취소 시 복원 + 이력 | 위 이어서 | 주문 1건 취소 | quantity=8, StockHistory(CANCEL) 1건 |
| STK-N4 | 이력 조회 | 위 시점 | GET /products/{id}/stock-history | 3건 응답 |
| STK-N5 | threshold 파라미터 | quantity=15 상품 | /low-stock?threshold=20 | 포함됨 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| STK-E1 | 음수 결과 | quantity=2 | PATCH delta=-5 | 409 INSUFFICIENT_STOCK |
| STK-E2 | ADJUST memo 누락 | - | PATCH delta=+1 memo=null | 400 |
| STK-E3 | threshold=0 | - | /low-stock?threshold=0 | 1로 클램프, 1 미만 없음 |
| STK-E4 | 동시 차감 | quantity=5, 동시 주문 10건 시도 | 동시 호출 | 일부 성공·일부 INSUFFICIENT_STOCK, 최종 quantity ≥ 0 |

## 4. 통합·회귀

- 1차 low-stock 기본 호출 동작 호환
- StockHistory 누락 0건 (트랜잭션 보장)

## 5. 합격 기준

- 이력 누락 0건, 음수 quantity 0건
- 동시 호출 시 최종 정합성 보장
