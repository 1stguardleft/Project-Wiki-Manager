# 대시보드 - 매출 집계 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 매출 집계
**SDLC 단계:** 테스트

## 1. 테스트 범위

`GET /api/dashboard/sales`의 합계 정확성과 0건/null 처리 등을 검증한다.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SALES-N1 | 단순 합계 | 주문 3건(10000/20000/30000원) | GET /sales | totalSales=60000 |
| SALES-N2 | 0건 | 주문 없음 | 동일 | totalSales=0 |
| SALES-N3 | 대량 | 주문 1000건 임의 금액 | 동일 | DB 합계와 일치, 응답 1.5초 이내 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| SALES-E1 | 취소 포함 | CANCELLED 주문 5만원 포함 | 동일 | 합계에 포함됨(상태 무관) |
| SALES-E2 | 단일 거대 금액 | 한 건 999,999,999원 | 동일 | 오버플로 없이 정상 반환 |

## 4. 통합·회귀

- 주문 추가/삭제 후 합계 갱신 확인
- 다른 대시보드 API와 동시 호출 시 정상 응답

## 5. 합격 기준

- 합계 결과가 DB 직접 SUM과 100% 일치
- 0건 상태에서 null이 아닌 0으로 반환
- 응답 시간 1.5초 이내
