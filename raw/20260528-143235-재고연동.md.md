# 주문 관리 - 재고 연동 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 재고 연동
**SDLC 단계:** 요구사항

## 1. 개요

주문 등록·취소에 따라 상품의 재고가 자동으로 변동되도록 한다. 별도 사용자 조작 없이 시스템 내부에서 처리된다.

## 2. 사용자 시나리오

- 영업 담당자가 주문 1건(수량 5)을 등록하면 해당 상품의 재고가 5 감소한다.
- 운영자가 주문을 CANCELLED로 변경하면 재고가 자동 복원된다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 연동-01 | 등록 시 차감 | 주문 등록 시 상품 quantity 감소 | 필수 |
| 연동-02 | 취소 시 복원 | CANCELLED 시 quantity 복원 | 필수 |

## 4. 관리 정보

| 항목 | 설명 |
|---|---|
| product.quantity | 주문/취소에 따라 변동 |

## 5. 업무 규칙

- 등록 시 재고 부족 검사는 1차에서 **수행하지 않는다**(음수 재고도 허용).
- 주문 삭제(DELETE)에서는 재고를 복원하지 않는다(CANCELLED 상태일 때만 복원).
- 동시성 보장 수준은 트랜잭션 격리수준에 의존.

## 6. 비기능 요구사항

- 차감/복원 추가 지연 100ms 이내.
