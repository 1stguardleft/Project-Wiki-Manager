# 공통/인프라 - 전역 예외 처리 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 공통/인프라 / 전역 예외 처리
**SDLC 단계:** 테스트

## 1. 테스트 범위

각 예외 타입이 정해진 응답 코드로 변환되는지.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| EXC-N1 | Validation 실패 | 필수값 누락 | POST | 400 + success:false |
| EXC-N2 | NullPointerException | 코드 버그 | API | 500 + success:false |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| EXC-E1 | 로그 적재 | 예외 발생 | API | ERROR 레벨 로그에 stacktrace |

## 4. 합격 기준

- 모든 예외가 표준 응답으로 변환
- 로그 누락 0건
