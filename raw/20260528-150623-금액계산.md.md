# 주문 관리 - 금액 계산 - 구현 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 금액 계산
**SDLC 단계:** 구현

## 1. 구현 범위

OrderService.create에서 product.price × quantity로 totalAmount를 산출해 Order에 저장.

## 2. 구현 항목 체크리스트

- [ ] OrderService.create에서 product 조회 후 가격 추출
- [ ] `long total = (long) product.price * quantity;`
- [ ] Order 엔티티에 totalAmount 저장
- [ ] 단위 테스트

## 3. 적용 기술

- 정수 연산 (long 캐스팅으로 오버플로 방지)

## 4. 단계별 작업 순서

1. Service 로직 → 2. 단위 테스트 → 3. 통합 테스트

## 5. 위험 요소

| 위험 | 대응 |

| int 오버플로 | long 캐스팅으로 안전 처리 |
