# 상품 관리 - SKU 식별 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 상품 관리 / SKU 식별
**SDLC 단계:** 요구사항

## 1. 개요

상품을 사람·시스템 모두 식별할 수 있는 SKU(Stock Keeping Unit)를 부여한다. SKU는 상품 등록 시 운영자가 직접 입력한다.

## 2. 사용자 시나리오

- 운영자가 신규 상품 등록 시 `MILK-1L-001` 같은 SKU를 입력한다.
- 검색 화면에서 SKU 일부를 입력해 상품을 찾는다(검색은 별도 기능, 본 서브도메인은 컬럼 정의 범위).

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| SKU-01 | SKU 입력 | 등록·수정 시 SKU 입력 | 필수 |
| SKU-02 | SKU 노출 | 상품 상세 응답에 SKU 포함 | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| sku | 필수 | 문자열 | 상품 식별자 |

## 5. 업무 규칙

- SKU는 자유 문자열 (1차 범위에서 형식 검증 없음).
- SKU 중복 등록 허용 (검증 없음).

## 6. 비기능 요구사항

- SKU 입력으로 인한 추가 부하 없음.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 빈 SKU 등록 | 400 오류 (필수 항목) |
