# 직원 관리 - 직원 기본정보 - 테스트 (1차)

**문서 버전:** v1.0 (1차)

**SDLC 단계:** 테스트

## 1. 테스트 범위

CRUD 5개 API 정상·예외, 부서 검증.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| EMP-N1 | 등록 | 부서 1건 존재 | POST | 201 |
| EMP-N2 | 목록 | 3건 | GET | 3건 |
| EMP-N3 | 상세 | id 보유 | GET /{id} | 200 |
| EMP-N4 | 수정 | id 보유 | PUT | 200 |
| EMP-N5 | 삭제 | id 보유 | DELETE | 204 |
