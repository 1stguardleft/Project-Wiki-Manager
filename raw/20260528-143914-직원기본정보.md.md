# 직원 관리 - 직원 기본정보 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 직원 관리 / 직원 기본정보
**SDLC 단계:** 요구사항

## 1. 개요

인사 담당자가 회사 직원의 기본 정보(이름·이메일·전화·직책)를 등록·관리할 수 있어야 한다.

## 2. 사용자 시나리오

- 인사 담당자가 신입 직원을 등록한다.
- 운영자가 전체 직원 목록을 조회한다.
- 매니저가 퇴사 직원을 삭제한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 직원-01 | 등록 | 신규 직원 등록 | 필수 |
| 직원-02 | 목록 | 전체 조회 | 필수 |
| 직원-03 | 상세 | 단건 조회 | 필수 |
| 직원-04 | 수정 | 정보 변경 | 필수 |
| 직원-05 | 삭제 | 직원 제거 | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| name | 필수 | 1~80자 | 이름 |
| email | 필수 | 이메일 형식 | 이메일 |
| phone | 필수 | 문자열 | 전화번호 |
| position | 필수 | 문자열 | 직책 |
| salary | 선택 | 정수 | 급여 |
| hireDate | 선택 | 날짜 | 입사일 |
| departmentId | 필수 | FK | 소속 부서 |

## 5. 업무 규칙

- 필수 항목 누락 → 등록 불가.
- 이메일 형식 위반 → 등록 불가.
- **이메일 중복 허용** (1차 범위).
- 직원 등록 시 부서 지정 필수 (1차 정책).

## 6. 비기능 요구사항

- 등록·조회 응답 0.5초 이내.

## 7. 예외 처리

|---|---|

| 이메일 형식 오류 | 400 |
