# 부서 관리 - 부서 기본정보 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 부서 관리 / 부서 기본정보
**SDLC 단계:** 요구사항

## 1. 개요

운영자가 회사의 조직 구조(부서)를 등록·관리할 수 있어야 한다. 부서는 직원 도메인의 기준 데이터.

## 2. 사용자 시나리오

- 인사 담당자가 신규 부서를 등록한다.
- 매니저가 부서 목록을 조회한다.
- 운영자가 폐지된 부서를 삭제한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 부서-01 | 등록 | 신규 부서 등록 | 필수 |
| 부서-02 | 목록 | 전체 조회 | 필수 |
| 부서-03 | 상세 | 단건 조회 | 필수 |
| 부서-04 | 수정 | 정보 변경 | 필수 |
| 부서-05 | 삭제 | 부서 제거 | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| name | 필수 | 1~80자, UNIQUE | 부서명 |
| description | 선택 | 문자열 | 설명 |
| createdAt | 자동 | timestamp | 등록 시각 |

## 5. 업무 규칙

- name은 시스템 전체에서 unique.
- 부서장(manager) 개념은 1차 범위 아님.
- 삭제 시 소속 직원이 있어도 삭제 허용 (1차 정책 — 직원의 departmentId는 NOT NULL이므로 운영상 위험).

## 6. 비기능 요구사항

- 응답 0.5초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 부서명 중복 | 409 DUPLICATE_NAME |
| 존재하지 않는 id 조회 | 404 |
