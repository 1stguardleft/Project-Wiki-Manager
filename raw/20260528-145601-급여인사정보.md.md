# 직원 관리 - 급여/인사 정보 - 설계 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 직원 관리 / 급여/인사 정보
**SDLC 단계:** 설계

## 1. 설계 개요

Employee 엔티티에 salary/position/hireDate 컬럼을 두고 단순 저장한다. 별도 인사 이력 테이블은 없음.

## 2. 구성 요소

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| Entity | Employee | 컬럼 보유 |
| Service | EmployeeService | salary 음수 검증 |

## 3. 데이터 모델

| 컬럼 | 타입 | 제약 |
|---|---|---|
| salary | bigint | nullable, ≥ 0 |
| position | varchar(40) | NOT NULL |
| hire_date | date | nullable |

## 4. API 인터페이스

별도 엔드포인트 없음 (Employee CRUD 응답에 포함).

## 5. 설계 규칙

- salary 음수 검증은 Service.
- position 자유 문자열.
