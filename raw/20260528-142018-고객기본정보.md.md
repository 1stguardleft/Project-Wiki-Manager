# 고객 관리 - 고객 기본정보 - 요구사항 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 고객 관리 / 고객 기본정보
**SDLC 단계:** 요구사항

## 1. 개요

영업 담당자가 거래처/소비자 정보를 등록·관리할 수 있어야 한다. 주문 도메인의 기준 데이터.

## 2. 사용자 시나리오

- 영업 담당자가 신규 고객(이름·이메일·전화·주소)을 등록한다.
- 운영자가 전체 고객 목록을 조회한다.
- 매니저가 폐쇄된 거래처를 삭제한다.

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| 고객-01 | 고객 등록 | 신규 고객을 등록 | 필수 |
| 고객-02 | 고객 목록 | 전체 목록 조회 | 필수 |
| 고객-03 | 고객 상세 | 단건 조회 | 필수 |
| 고객-04 | 고객 수정 | 정보 변경 | 필수 |
| 고객-05 | 고객 삭제 | 고객 제거 | 필수 |

## 4. 관리 정보

| 항목 | 필수 | 형식 | 설명 |
|---|---|---|---|
| name | 필수 | 문자열 | 고객명 |
| email | 필수 | 이메일 형식 | 이메일 |
| phone | 필수 | 문자열 | 전화번호 |
| address | 선택 | 문자열 | 주소 |
| city | 선택 | 문자열 | 도시 |
| country | 선택 | 문자열 | 국가 |

## 5. 업무 규칙

- 필수 항목 누락 → 등록 거부.
- 이메일 형식 위반 → 등록 거부.
- **동일 이메일 다중 등록 허용** (1차 범위 내).
- 삭제는 진행 중 주문 여부와 무관하게 가능.

## 6. 비기능 요구사항

- 등록·조회 응답 0.5초 이내.

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 필수 누락 | 400 |
| 이메일 형식 오류 | 400 |
| 존재하지 않는 id | 404 |
