# 주문 관리 - 재고 연동 - 구현 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 재고 연동
**SDLC 단계:** 구현

## 1. 구현 범위

OrderService에서 ProductService(또는 Repository)를 호출해 quantity를 변동. 재고 부족 검증 없음.

## 2. 구현 항목 체크리스트

- [ ] `ProductService.deductStock(productId, qty)` / `restoreStock(productId, qty)` 메서드
- [ ] OrderService.create에서 deductStock 호출
- [ ] OrderService.updateStatus CANCELLED 분기에서 restoreStock 호출
- [ ] 트랜잭션 내 호출

## 3. 적용 기술

- @Transactional 전파(REQUIRED)

## 4. 단계별 작업 순서

1. Product에 차감/복원 메서드 → 2. Order에서 호출 → 3. 통합 테스트

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| 음수 재고 발생 | 1차 허용, 2차에 INSUFFICIENT_STOCK 도입 |

## 6. 검증 포인트

- 등록 후 product.quantity -= order.quantity
- CANCELLED 후 += 복원
