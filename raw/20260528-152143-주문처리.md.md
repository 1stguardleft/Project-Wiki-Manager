# 주문 관리 - 주문 처리 - 테스트 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 주문 관리 / 주문 처리
**SDLC 단계:** 테스트

## 1. 테스트 범위

CRUD 4개 API의 정상·예외 동작과 트랜잭션 일관성.

## 2. 정상 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| ORD-N1 | 등록 | 고객·상품 존재 | POST | 201, totalAmount 산출 |
| ORD-N2 | 목록 | 3건 | GET | 3건 |
| ORD-N3 | 상세 | id 보유 | GET /{id} | 200 |
| ORD-N4 | 삭제 | id 보유 | DELETE | 204 |

## 3. 경계·예외 시나리오

| TC-ID | 시나리오 | 전제 | 실행 | 기대 결과 |
|---|---|---|---|---|
| ORD-E1 | 존재하지 않는 고객 | customerId=999 | POST | 404 |
| ORD-E2 | 존재하지 않는 상품 | productId=999 | POST | 404 |
| ORD-E3 | quantity 0 | quantity=0 | POST | 400 |
| ORD-E4 | DELETE 후 재고 미복원 | 등록 후 삭제 | product.quantity 확인 | 변동 없음 |

## 4. 통합·회귀

- 등록 시 재고 차감 + totalAmount 정확성 동시 확인
- 다수 동시 등록 시 트랜잭션 격리 동작

## 5. 합격 기준

- 정상 TC 100%, 응답 1초 이내
