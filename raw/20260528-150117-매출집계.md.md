# 대시보드 - 매출 집계 - 구현 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 대시보드 / 매출 집계
**SDLC 단계:** 구현

## 1. 구현 범위

DashboardController에 `/sales` 엔드포인트 추가, OrderRepository의 SUM 쿼리로 매출 합계 반환.

## 2. 구현 항목 체크리스트

- [ ] `OrderRepository.sumTotalAmount()` 추가 (`@Query` 사용)
- [ ] SalesResponse DTO 정의 (`totalSales`)
- [ ] DashboardController에 `GET /api/dashboard/sales` 추가
- [ ] null 합계 처리(주문 0건 시 0 반환)
- [ ] 단위 테스트 작성

## 3. 적용 기술

- Spring Data JPA `@Query("SELECT SUM(o.totalAmount) FROM Order o")`
- `Optional<Long>` → 0 변환 패턴

## 4. 단계별 작업 순서

1. Repository SUM 쿼리 작성 → 2. null 보정 → 3. DTO → 4. Service → 5. Controller → 6. 테스트

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| SUM 쿼리가 풀스캔으로 동작해 데이터 증가 시 느려짐 | 1차에는 인덱스 없이 진행, 2차에서 검토 |

## 6. 검증 포인트

- 주문 0건 → 0 반환
- 취소 주문 포함 합산이 의도대로 동작하는지
