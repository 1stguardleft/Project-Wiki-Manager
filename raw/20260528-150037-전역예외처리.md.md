# 공통/인프라 - 전역 예외 처리 - 구현 (1차)

**문서 버전:** v1.0 (1차)
**도메인 / 서브도메인:** 공통/인프라 / 전역 예외 처리
**SDLC 단계:** 구현

## 1. 구현 범위

GlobalExceptionHandler 클래스를 신설해 두 가지 패턴(Validation 400 / 그 외 500)을 처리.

## 2. 구현 항목 체크리스트

- [ ] `@ControllerAdvice class GlobalExceptionHandler`
- [ ] `@ExceptionHandler(MethodArgumentNotValidException.class)` → 400
- [ ] `@ExceptionHandler(ConstraintViolationException.class)` → 400
- [ ] `@ExceptionHandler(Exception.class)` → 500
- [ ] log.error(예외 메시지, 예외)
- [ ] 통합 테스트

## 3. 적용 기술

- Spring `@ControllerAdvice`
- SLF4J 로깅

## 4. 위험 요소

| 위험 | 대응 |
|---|---|
| 500 일괄로 정보 손실 | 1차 범위, 2차에서 세분화 |

## 5. 검증 포인트

- 모든 도메인에서 발생한 예외가 일관 응답
- 로그에 stacktrace 포함
