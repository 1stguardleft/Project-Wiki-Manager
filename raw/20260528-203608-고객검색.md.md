# 고객 관리 - 고객 검색 - 구현 (2차)

**문서 버전:** v2.0 (2차)
**도메인 / 서브도메인:** 고객 관리 / 고객 검색
**SDLC 단계:** 구현
**변경 요점 (vs 1차):** 검색 API 신설, 인덱스 추가.

## 1. 구현 범위

CustomerController에 `/search` 엔드포인트, Repository에 derived query, 인덱스 추가.

## 2. 구현 항목 체크리스트

- [ ] `Page<Customer> findByNameContainingIgnoreCaseOrPhoneContaining(String name, String phone, Pageable pageable)`
- [ ] CustomerController.search(@RequestParam ...) 핸들러
- [ ] DTO: CustomerSearchResponse (id/name/email/phone)
- [ ] DDL: `CREATE INDEX idx_customer_name ON customer(name); idx_customer_phone`
- [ ] 파라미터 검증 (둘 중 하나 필수)
- [ ] size 클램프 (1~100)
- [ ] 단위 + 통합 테스트

## 3. 적용 기술

- Spring Data Pageable + derived query
- DB 인덱스
- DTO 매핑

## 4. 단계별 작업 순서

1. Repository 메서드 → 2. DTO → 3. Service 검증 → 4. Controller → 5. 인덱스 적용 → 6. 테스트

## 5. 위험 요소

| 위험 | 대응 |
|---|---|
| LIKE 양쪽 와일드카드로 인덱스 미사용 | 데이터 규모 모니터링, 필요 시 full-text 인덱스 도입 |

## 6. 검증 포인트

- 이름/전화번호 단독·복합 조건
- 페이지 경계 (마지막 페이지 size 미만)
