## 1. 최종 아키텍처 요약

* **완성된 아키텍처 핵심:** LangGraph 기반 **13개 에이전트 적재 파이프라인** + 벡터/LLM 2단계 판정 + 하이브리드 검색 + **SSE 실시간 시각화**로, 흩어진 개발 산출물을 **자동으로 한 권의 위키로 통합**해 주는 풀스택 시스템.

* **최종 산출물 형태:** **풀스택 웹 애플리케이션** — 적재 화면(파일/URL 입력) · 워크플로우 시각화 화면 · 위키 뷰어/검색/질의응답 화면 · 충돌(diff) 확인 화면을 모두 한 앱에서 제공.

* **Agent 구조:**
  - **백엔드 (FastAPI + LangGraph):** 수집 → 파싱 → 정규화 → **도메인 분해(분기)** → 청킹 → 임베딩 → 유사도 → 충돌 판정 → 병합 → **누락 검토(↺ 병합으로 1회 재시도)** → 상호참조 → 인덱싱 → 로깅. 다도메인 문서는 자식 run으로 **병렬 처리**.
  - **저장소:** 마크다운 파일(`wiki/`) + 그래프(`edges.jsonl`) + 벡터 DB(Chroma) + 원본 불변(`raw/`).
  - **프론트엔드 (React + React Flow):** SSE 스트림을 받아 노드를 순차 점등, 우측 패널이 직전 완료 단계 결과를 자동 추적.

## 3. 창출된 핵심 가치

### 3-1. 비즈니스 가치

* **개발 팀의 산출물 관리 자동화** — 요구사항/설계/테스트 문서가 흩어져도 LLM이 자동으로 한 권의 위키로 정리.

* **중복·모순 자동 정리** — 같은 기능의 v1/v2 문서가 따로 들어와도 한 페이지로 합쳐 주고, 모순 시 충돌 표시.

* **온보딩/지식 검색 가속** — 인용 기반 질의응답으로 새 인원이 "○○ 정책이 뭐야?"라고 물으면 근거 페이지와 함께 답변.

### 3-2. 기술적 가치

* **단순 RAG가 아닌 Multi-Agent + 그래프 분기/반복 구조** — LangGraph의 conditional edge로 누락 보완 루프와 도메인 병렬 분기 구현.

* **벡터 검색의 false-positive를 LLM judge로 보정하는 2단계 패턴** 정립.

* **외부 API 없이도 전체 파이프라인이 끝까지 돌아가는 오프라인 폴백** — 1536차원 해시 임베딩으로 데모/교육 환경 비용 0원.

* **백엔드 SSE → 프론트 React Flow** 실시간 시각화로 에이전트 디버깅이 즉시 가능.

## 4. 운영 및 보안 고려 사항

* **API 키 관리:** OpenAI/Azure 키를 **다른 환경변수로 분리** 후 우선순위(Azure → OpenAI → offline)로 자동 결정. `/api/health`로 현재 모드 즉시 확인.

* **파괴적 액션 가드:** 위키 데이터 초기화 같은 destructive 버튼은 **2단계 confirm 행**을 한 번 더 띄우고 위험 버튼으로 포커스 강제 이동.

* **원본 데이터 보존:** 초기화 시에도 `raw/`의 원본 문서는 **건드리지 않고** 위키 데이터만 삭제 → 언제든 재적재 가능.

* **장애 대응:** SSE 끊김 시 브라우저가 자동 재연결, 백엔드가 **이벤트 이력을 처음부터 재전송**해 캔버스 그대로 복원. 단일 노드 실패는 `failed`로만 발행해 다른 분기에 영향 없음.
