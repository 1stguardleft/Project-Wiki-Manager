# 시연 영상 녹화 계획 (v1, 초안)

> **목적**: Project Wiki Manager의 핵심 가치 — "흩어진 개발 산출물 →
> 멀티 에이전트가 자동으로 정합 위키로 누적·유지" — 를 5~7분 안에 한
> 흐름으로 보여준다.
> **대상 시청자**: 사내 시연·심사 위원·PoC 평가자 (개발 비전공 포함).
> 추상적 용어 대신 "보이는 동작 + 변화"로 설명한다.
> **길이 목표**: 6분 (±1분).
> **톤**: 차분한 해설 + 빠른 화면 전환. 자막은 한국어 한 줄.

---

## 1. 사전 준비

### 1.1 환경
| 항목 | 값 | 비고 |
|---|---|---|
| 해상도 | 1920×1080 (16:9) | 4K로 녹화 후 1080p 다운스케일 권장 |
| 브라우저 | Chrome / Edge 1280×800 창 | 사이드바 펼친 상태 |
| 백엔드 | `uvicorn app.main:app --port 8000` | Azure OpenAI 활성(시연 안정 목적) |
| 프론트 | `npm run dev` (5173) | 빌드(`dist`) 서빙도 가능 |
| 결정성 | `STEP_DELAY_SEC=1.0` (기본값 유지) | 각 노드 1초 페이싱 — 시각화 가독성 확보 |
| 마이크 | 외장 USB 마이크 | 클릭 소리 줄이기 위해 트랙패드 권장 |

### 1.2 데이터 시드
- `wiki/` 리셋 → **빈 상태에서 시작** (`POST /api/wiki/reset` 또는 위키 뷰어의 데이터 초기화 버튼)
- `demo/` 폴더의 1차 ~ 2차 소스 일부 미리 확인:
  - **1차 적재용**: `demo/1차/01-요구사항/대시보드/매출집계/매출집계.md`
  - **2차 적재용**(병합/충돌 시연): `demo/2차/01-요구사항/대시보드/매출집계/매출집계.md`
  - **분해 데모용**(여러 도메인 혼재 문서): 가급적 도메인 2~3개 섞인 묶음 파일 1개 미리 선별
- 잔여 raw 파일 정리(`raw/` 비워두면 클린 시연)

### 1.3 화면 상태
- 브라우저 새 시크릿창(확장 프로그램·캐시 영향 차단)
- DevTools 닫기, 북마크바 숨기기, 시계만 노출
- 알림(슬랙·메일) 무음/숨김

### 1.4 녹화 도구
- OBS Studio (영상) + 별도 오디오 트랙(내레이션·BGM 분리)
- 마우스 클릭 하이라이트 ON (커서 강조)
- 캡션은 후반작업에서 SRT로 별도 부착 (자막 한 줄 ≤ 22자)

## 2. 영상 흐름 한 줄 요약

```
[0. 문제 정의] → [1. 적재 시작] → [2. 멀티 에이전트 시각화] →
[3. 자동 누적된 위키 페이지] → [4. 2차 적재로 충돌·병합] →
[5. 지식 그래프 + 구조화된 연관 근거] → [6. 마무리·다음 단계]
```

## 4. 컷·전환·자막 가이드

- **컷 길이**: 평균 6~10초. 한 정보(자막 한 줄)당 한 컷.
- **전환**: 같은 뷰 안 = cut, 뷰 전환 = 0.2s cross-dissolve.
- **줌**: 노드 상세 패널·표 셀처럼 작은 글자는 1.3~1.5× 줌 + 마우스 강조.
- **자막**: 영상 하단 안전구역 80px, 글자 24px, 라인 한 줄, 1.5s 이상 유지.
- **음성**:
  - 내레이션 −16 LUFS 통합 라우드니스.
  - BGM은 잔잔한 lo-fi/ambient, −28 LUFS, 마지막 10초 페이드아웃.
