### AI Master Project

## 프로젝트 명

Project Wiki Manager

***

## 배경 및 문제 정의

### 현재 상황 (As-Is)

* 웹페이지, Confluence 등 다양한 소스에 문서가 분산되어 있음
* 동일하거나 유사한 내용의 문서가 중복 존재
* 문서 구조, 포맷, 표현 방식이 제각각
* 최신 정보가 어디에 있는지 판단하기 어려움

### Pain Point

* 문서 탐색 및 이해에 불필요한 시간 소모
* 중복 문서로 인한 혼선 및 의사결정 지연
* 내용 불일치로 인한 품질 저하
* 문서 정리 작업이 수작업 중심

### 기회 요인

* LLM을 활용하여 문서 간 의미적 유사도 판단 가능
* 구조화되지 않은 문서를 정규화(Normalize) 가능
* 중복/유사 문서를 자동 병합(Merge) 가능
* 지속적인 문서 정제 파이프라인 구축 가능

## 프로젝트 목표

### 정성적 목표

* 목표 1: 분산된 문서를 하나의 일관된 형태로 통합

* 목표 2: 중복 및 유사 문서 자동 정리

* 목표 3: 사람이 이해하기 쉬운 형태로 재구성

### 정량적 목표 (KPI)

| 성과 지표     | 목표 수치  | 측정 방법             | 현재 수준 |
| --------- | ------ | ----------------- | ----- |
| 문서 중복 제거율 | 60% 이상 | 병합 전/후 문서 수 비교    | 높음    |
| 문서 탐색 시간  | 50% 감소 | 동일 정보 탐색 시간 비교    | 높음    |
| 정제 정확도    | 80% 이상 | 수동 검증             | 없음    |
| 자동 처리 비율  | 70% 이상 | 전체 문서 대비 자동 처리 비율 | 낮음    |

## 핵심 기능 정의

1. Ingestion (수집)

   * 웹페이지, Confluence 문서 수집

   * HTML/Markdown 등 다양한 포맷 처리

2. Normalization (정규화)

   * 문서 구조 재구성 (제목, 본문, 리스트 등)

   * 불필요한 요소 제거

   * 의미 단위로 분해 (Chunking)

3. Similarity Detection (유사도 분석)

   * 문서 간 의미 기반 유사도 계산

   * 중복/유사 문서 그룹화

4. Merge (문서 통합)

   * 유사 문서를 하나의 문서로 통합

   * 충돌 내용 정리 및 보완

5. Output Generation

   * 정제된 문서를 Markdown 등으로 생성
